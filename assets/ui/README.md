# R1 玄门秘卷界面资源

视觉来源为用户提供的本地 `opus美术集成/坐天观井_玄门秘卷_UI原型 .html`。正式界面保留其纸墨朱砂配色、题签、印令、符签、卷架、漏刻和命簿结构，由 `secretScrollHost.js` 排布现有控件；原型内的虚构人物、事件与世界图不作为游戏数据使用。

卜算子插画为用户提供的 `opus美术集成/卜算子默认.png` 原文件，随包保存在 `assets/characters/busanzi/materials/busanzi_illustration.png`；SHA-256 为 `ebee153c54cf79276c958a290340a409de4ce41d30b10fbd6c1807508f534651`。肖像入口仍打开 A1 三维 Viewer。

`fonts/` 包含原型指定的 Ma Shan Zheng 与 Noto Serif SC（400/700）字体，由 Google Fonts 的 `text` 字符子集接口取得，共约 1.1 MB；超出子集的汉字使用系统宋体回退。运行时从本地加载，无外部字体请求。来源为 [Google Fonts](https://fonts.google.com/)，两款字体的官方 SIL Open Font License 分别保存在 [Ma Shan Zheng OFL](./fonts/ma-shan-zheng-OFL.txt) 与 [Noto Serif SC OFL](./fonts/noto-serif-sc-OFL.txt)。
