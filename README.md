# 水墨沙盒 · 坐天观井

世界盒子式的修仙沙盒。**你不是其中任何一个人，你是这片山水的天道。**

改山河、拨因果，然后看它自己活下去——凡人结庐成村，修士拜师结怨，宗门顺着河谷扩张，
有人渡劫飞升，也有人被天雷劈死。

> 版本 **v0.1**（首个玩家测试版）

## 启动

Windows：双击 **`启动水墨沙盒.bat`** —— 会自动起本地服务器并打开浏览器。

其他平台：

```bash
node scripts/inkbox-server.mjs --port=4180
# 然后打开 http://127.0.0.1:4180/inkbox.html
```

需要 **Node.js 18+**。**零依赖，不需要 `npm install`。**

## 说明

- 纯前端 + 一个静态服务器：没有后端、没有数据库，存档在浏览器 localStorage 里。
- 地图、人物、法宝全部是程序生成的，**没有任何图片素材**。
- 世界会一直自己跑。你能做的只有两件事：**改山河**，和**拨因果**。
