## 玩家行为与实现

WASD 不再把秒再次除以 1000；文本输入与模态层仍独占输入，关闭帮助、人物卡和符匣后恢复相机。顶栏直接切完整凡界、上界、幽冥及对应纸色；局部视界仍使用原 selection/Region/rift 管线。

所有正式工具可从 3D 工具匣选择，保留 click、drag、select 语义。未开放位面明确拒绝并留在 3D。赐灵根取实际被点中的存活 entity ID，悬停显示人物姓名。R1 自然雕刻仍保留其既有笔形，与 Canvas 共用 World、terrainEdit 和本轮 localWater；没有改写 R1 为另一套世界或连续水物理。

局部整理只在实际编辑/到期事件发生时运行。单窗最多 81×81 = 6,561 格、32 轮；普通水笔整笔合并，128 个相邻采样只整理一次。长笔使用共享边节点的 81 格窗口，并分摊总轮数预算；达到范围/轮数限制时记录 capped。所有可移动水都作为有限水处理，海水局部补坑也会有小幅水位下降；不凭海平面数值把孤立水池升级为无限海源。整理自身守恒，地形升降前置水深调整保留原静态地形语义。

永久水、河流基底与每次限时洪水分别保留身份。总水面计算包括其他未到期洪水层；玩家抽水先扣临时层，过期水不复活。默认遵守渐开地图的操作边界。未提交失败水笔按 History 当前快照恢复水层、自然事件所有权与派生量；取消地形笔画不会播放成功水响应。

表现层只消费成功工具或真实水变化事件，不再次结算伤害。ThreePowerFx 复用 3 个实例批次，最多 24 个事件、288/192/48 个 stroke/leaf/ring 实例，具距离降级、区域所有权与释放。植林、沃野、雨、火、灵脉、赐灵根、雷、陨石、地震和水响应有不同短时模板。换世界清空，暂停时仍可看完短动画。

玩家撤销/重做按钮、快捷键与旧提示已移除；内部 History、旧档解析、取消笔势与失败回滚保留。E0 记录落笔事实。同一降灾按事件 ID 将起因/结局合在一条大事记，编年史保留两阶段；旧进行中存档按严格 ID 前缀及起始日回填，不合并多年后独立事件。
