## 入口与效果

启动 `npm run dev -- --port 4262`，进入 [墨焰展厅](../../research/nether-strata/index.html)。默认展示完整墨焰；`?look=legacy` 或「D-N2A 原版」一键回退。五处巡境为全卷、断狱台地、墨骨绝壁、无间深渊、崖脚阴焰，沿用原相机的近中远、旋转、缩放和平移。

| 快速对照 | Tone | Soulfire | Cliff ink | Low mist |

## 实现与工程边界

`NetherInkflame.js` 从既有 `ElevationField.node()` 读取表现高度，用自适应高程区间、邻域低洼 / 凸缘、真实黄泉湿域和阴气派生 upper / middle / lower / seep。四通道 RGBA8 只作分类，既不储存权威地面也不参加拾取。着色器结合实际插值的 world Y 与该只读上下文，保持垂直层次连续，并让同高处的凹陷与阴湿区具有不同白化、外渗强度。

`PigmentTerrainMaterial` 保留骨白台面，上部立面积墨、中部灰断、低部冷白；虚白底和向上移动的细缓噪声均锚定世界坐标。`NetherCliffLayer` 在原共面批次上增加疏密不同的主层、破笔、局部下坠湿墨与淡化的崖脚；`TerrainLineArt` 仅调整上下层透明度，上缘清楚、下缘消隐，不重做线提取或地形几何。

`NetherSoulfireLayer` 归 Stage 所有，最多选择 12 处真实干燥低地 / 渗口，以两片固定交叉平面呈现克制的白焰魂息。它不跟随镜头、不可拾取、遵循既有 Region 的完整景物足迹裁剪。静态使用固定形态，缓流使用调用者传入的 Host 表现时间；没有另一套模拟时钟、实体或随机事件。崖脚巡境取实际魂息锚点，便于近看。

`PlaneStage.setNetherInkflame()` 是显式候选 opt-in。正式默认不分配该层；四项全部关闭释放遮罩及薄片资源，材质参数归零并借回原有纹理。地形 / 阴湿事实、高程剖面变化才重建派生场；闲帧只更新少量时间 uniform，不扫描全图、不重写实例或上传遮罩。换 World、退出和重复释放均有验证。

未修改 `World.js`、`advance.js`、`save.js`、`main.js`、正式生成器、候选生成器、`ElevationField`、地形拓扑、拾取与相机源码。没有新可通行地面、正式通行裁决、存档字段、体积云或魂屑粒子；模拟日始终为 0。新增模块留在既有渲染链路，未另起地形引擎。

完整模式相对原版的成对 RAF P95 差值：中卷 +.1～.2 ms，广卷 +.0～5.6 ms；CPU 更新 / 提交差值含负值，不能解释为优化旧逻辑带来的稳定提速。16 个最终窗口中，中卷首个完整窗口有 1 次 >50ms 间隔，其余为 0。初轮广卷完整模式曾测得 44.1～50.1ms 长尾；去除新增噪声中的三角函数、跳过非低层的魂火计算后，最终以上表为准。有限样本不足以单独归因全部时序波动。

这些是预热后的展厅样本，不包含生成 / 首次编译时延，不代表正式游戏性能封板或稳定 60 FPS。没有 GPU timer query；CPU 提交时间不冒称 GPU 执行时间，也不以关掉大量旧内容掩盖开销。

中间失败保留在 ignored `reports/local/dn2a1/`：初版截图门槛误用了文本长度；静态 PNG 严格哈希误判了单字节边缘波动，改为解码像素并限制误差；两轮 CIM / 进程退出确认失败后，依据各自端口与绝对路径核实零存活浏览器引用，再仅清理本任务临时目录；另一次浏览器在场景加载前报 `ERR_INSUFFICIENT_RESOURCES`。这些不计为最终通过，最终新会话使用当前源码完成全部检查及自动清理。

近景仍保留既有格网折面、切缝交会的薄岩脊和部分锯齿结构线。魂息有意保持很弱，远景主要读上下墨色，细微缓流适合崖脚近看；未把这些限制包装为最终美术封板。下一步若进入 D-N2B，先由用户裁决整体画面与低层强度，再单独处理正式通行、高程保存或资源接入；本包不提前执行这些裁决。

运行时四项全关或选「D-N2A 原版」回退；需要撤销整个美术包时对本包提交执行常规 Git revert，回到 `baf1dbd` 的 D-N2A 表现。无需迁移正式存档，不删除其他候选或工作树。
