# E1C temporary-view mutation audit

The audited interval is ONLY the stock synchronous mortal Life entity loop. All Life method identities must match the module's captured originals; overridden methods use legacy scans. No production Proxy exists. This audit is source-bound, not a promise about arbitrary injected callbacks/getters or future unnotified writes inside the interval.

| Native path | Relation to interval | View handling / evidence |
|---|---|---|
| Life.processPendingSpawns / spawn | Before interval | Build sees appended births. Existing birth/source/ID rules unchanged. |
| World.addEntity | Existing append | O(1) invalidation after original mutation; formal add fixture primes views then tests fallback. |
| World.removeEntity | Existing swap/pop | O(1) invalidation after original mutation; formal remove fixture covers changed order. |
| Life.step death/ascension stable compaction / onDeath | After finally closes interval | No map or spatial state survives compaction, resurrection, reincarnation or possession callbacks. Original sweep still settles every entity. |
| planes.arriveUpper direct push | Different World/plane | No mortal view serves upper identities; original scans there. |
| possession nether splice / nether births | Different World and post-loop | No owned view; original scans. |
| io/save restoreWorld array replacement / newWorld | Outside interval/new identity | Fresh WeakMap scope; raw imported IDs are not assumed validated. Duplicate/malformed IDs/repeated refs disable view. |
| Direct push/splice/same-length replacement between calls/steps | Outside interval | Unowned read scans; next owned pass builds from current array. Controlled replacement/order/compaction fixtures compare complete maps. Length alone is NOT a same-length mutation detector. |
| Life.stepEntity ground-escape teleport | Inside interval | Both x/y written, then sync before eating/effect queries. |
| Life.moveTowards | Inside interval | Finally sync covers every return/exception after native substeps. Test-only Proxy observes actual writes to another actor; subsequent queries match old map and Life.grid buckets remain unchanged. |
| transit arrival x/y | Outside interval | Next pass rebuilds; unowned reads scan. |
| upperLife.moveSpatially / nether movement | Different World/controller | No owned mortal index. |
| attack/heal/state/faction/relation change | Live inside interval | Spatial membership is position-only; eligibility/health/state/faction/relation facts are read again each query. Death does not prematurely remove a still-present row. |

Narrow searches covered direct x/y assignments, Object.assign/destructuring patterns and synchronous calls from stepEntity. No native mortal in-loop list mutation or other-actor position write was found beyond these displacement paths. New inside-loop mutation sources must notify or disable the view and receive renewed source/cost review. Uncertainty uses original full scanning, with counted fallback; no object is excluded to meet a budget.

All implementation stages retain fixed #66 per-axis Object.is, complete World/all-runtime/RNG, sourceTag frequency, independent v11 forks and original three-realm/save gates. Actual production hashes, controlled cases and native costs are in the stage acceptance JSON files. See WX_E1C_L0_PROOF.md.
