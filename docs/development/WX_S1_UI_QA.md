# WX-S1 玩家界面验收

命令：`node scripts/inkbox-wx-s1-browser.mjs`。证据目录：`reports/local/wx-s1/browser/`，机器清单 `acceptance.json`。最终交付提交与最后复跑状态以 [交付记录](./WX_S1_DELIVERY.md) 为准；施工期浏览器报告同时记录实际 HEAD、脏文件清单及脚本 SHA256，不将上游成功结果冒充本轮验收。

本机 Edge **156.0.4314.58**，仓库隔离 CDP、自有 IPC 服务器，每次启动独立 profile。Tabbit 稳定启动器缺失（技能故障路由判定安装不可用），故使用项目既有浏览器工具。受限环境的 WMI 所有权查询被拒后，通过已授权的提升运行完成自有进程验证和清理；不连接或关闭用户浏览器。软件 WebGL 仅证明功能，不证明成熟世界 GPU 性能。

## 覆盖

Canvas 1366×768、Canvas 390×844、Three 1366×768。三视口均经正式创世、暂停、保存控件、自然检查点导入、命簿展开及「经历 → 因果拾章 · 读取 / 刷新」，再经正式存读档回访同一对象。Three 核验 active、同 World 及实际 WebGL context / draw calls。

自然来源为 `reports/local/wx-s1/natural/20260914-100y-save.json`。保持凡间原有事实与 RNG，按 WX-D 原生浏览器恢复方式补充新生成的控制上界/幽冥，以满足正式加载器运行时协议。控制位面不代表自然三界长测。

秦少舒 `mortal:40` 的自然故事包含第23229日受江霜宁援助、第23478日付费护关、第25548日恢复142.6气血等不同日正式节点。展开来源可查正式经历键和费用。护关结果明确说明不等于目标突破成功。旧恩人死亡或缺少本世身份时，链接禁用并给出原因；没有按姓名定位。

自然地方旧闻从真实有源聚落检视打开。原物入口另用明确标注的受控路径：在自然查询与存读档验证结束后，对具资格的现有人物调用正式 `forgeArtifact`、`toGround`，使用夹具专属常量 RNG。该原物不计入自然样本。验证原物检视入口、来源卡、正式导航和原物不再存在后的拒绝跳转。

每个视口另验证：

- 暂停时连续100次只读投影，正式保存数据和人物 Profile 逐字一致；缺失身份不可定位。
- 存读档前后故事键、取证日及玩家可见摘录全文一致。
- 故城及原物旧闻打开后主动 `updateHud()`，仍保留原取证快照；不在 HUD 编译故事。
- 窄屏命簿宽度不超过视口；无页面异常和控制台错误。
- 结束后仅清理本次自有 Edge 进程和临时 profile，报告记录清理证据。

## 截图与限制

每个视口保存 `*-natural-story.png`、`*-settlement-old-news.png`、`*-controlled-original.png`。已目视390px截图：标题、时间线、证据键和禁用理由可读，无横向溢出。截图为真实页面输出，没有合成故事或添加自然回助。

本专项使用正式人物选择和地点检视入口打开已知 ID，再用原生鼠标点击命簿、来源、存读档及旧闻控件；未宣称地图像素拾取、完整 Browser Smoke、硬件 GPU 或800年 Nightly 通过。100次验证是读投影纯度检查，不是100次真人点击或成熟帧率封板。
