## 场景取得与加载

G8 归档没有终局完整实体快照或全部终局 RNG 游标；世纪 JSON/CSV、日志和工作簿是统计证据，不能导入为游戏存档。本次未登记到可直接加载且来源完整的 G8 成熟世界快照，也没有为建档重新推进几百年。

后续专项取得快照时，须记录生成源码 SHA、种子、尺寸、实际年份/日数、各界人口、视界开关和时间表、文件 SHA256、生成方式及运行期检查点是否完整。使用正式页面的「导入」加载由游戏导出的真实存档，或继续使用原浏览器存档槽；G8 新档通过原生保存/导出同时捕获运行期快照。Node 统计对象不能直接改名充当存档，不通过批量投放或修改人口字段伪造成熟世界。

有有效快照后，从同一快照分别开始各场景，记录加载后的世界摘要与镜头位置。正式存档地形仍有原有 16 位量化误差，比较应使用同一加载结果。旧档没有保存过的历史 RNG 游标无法倒推，不能当成完整确定性续跑样本。

## 后续真实浏览器测量

| 场景 | 验证目标 | 最少记录 |
| --- | --- | --- |
| 成熟世界暂停，3D 近景 | 纯渲染和镜头操作成本 | 固定镜头与受控移动分别采样，记录 Draw Call、三角形、渲染 CPU 与 RAF |
| 成熟世界正常推进 | 模拟更新与绘制叠加成本 | 倍速、实际推进游戏日、模拟更新 CPU、绘制 CPU 与 RAF |
| 成熟世界密集村镇 | 人物、建筑与拾取成本 | 同一村镇/人物身份、可见数量，悬停和检视操作耗时 |
| 成熟世界森林近景 | 植被与 GPU 批处理成本 | 同一森林位置/LOD、可见实例、Draw Call、上传量与 RAF |

每组记录设备 CPU/GPU、浏览器版本、渲染后端、分辨率、DPR、URL 参数、预热与采样时长、P50/P95、长帧和错误。模拟、渲染、交互分别统计；先暂停测绘制，再测推进叠加，交互用相同操作轨迹。RAF 是呈现间隔，CPU 渲染提交时间不是 GPU 执行时间；只有实际采得 GPU 时间才报告该项。

800 年 Node 长局与实时浏览器渲染是两种负载。**1,968,625 ms 不能换算为实时 3D FPS**，Fast/Heavy 或软件光栅功能通过也不能替代真实设备性能结论。性能专项另行采集数据；本轮没有 GPU A/B、跨设备封板或新框架。

基线保留正式默认植被路径；[R3D-S1 PR #51](https://github.com/sjh20016/inkbox/pull/51) 仍为 `CONDITIONAL`、默认关闭，须在独立专项中评估。与 G8 的集成文件及恢复契约接线见 [G8-M1 合流报告](./G8_M1_MERGE_REPORT.md)。
