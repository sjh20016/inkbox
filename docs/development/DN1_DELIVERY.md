## 运行与回退

```sh
npm ci
npm run dev -- --port 4255
```

- 正式游戏：`http://127.0.0.1:4255/inkbox.html?renderer=3d`，通过顶部「幽冥」进入整界。
- [隔离试卷](../../research/nether-landscape/index.html)：通过同一服务器打开 `/research/nether-landscape/index.html`，支持四种画幅、整数种子 0、原版/新版、巡境、笔墨对照及实际落笔。
- `&netherLandscape=off` 回退旧黄泉/地域表现及默认 line-c；`&nether=line-c` / `line-a` / `ink` 保留显式笔墨对照。`scenery=off` / 正式符匣「画中景」关闭景物与阴雾，河面独立保留。
- 幽冥深色 UI 以既有 `data-r1-realm="nether"` 为条件，使用原型色值 `#161513 / #25221e / #ece3cf / #d0583f`。离开幽冥整界恢复各界样式。纯局部视界仍使用其宿主位面的 UI。

试卷使用正式 World、PlaneStage、Render3DHost、坐标、高程、拾取和线刻。它不调用模拟推进；页面明确标注候选和无正式存档导出。没有另造地图引擎或世界时钟。

## 实现与一致性

`worldgenNether.js` 完全未改。候选入口 `world/netherLandscape.js` 与纯分类 `world/netherGeography.js` 独立；未添加持久 biome/yin 数组。`NETHER_REGIONS` 定义河川、山岭、荒原、古冢和深谷的布局资格与密度，古冢属于装饰，不制造历史地点。

`NetherRiverLayer` 复用生产 `WaterGpuSurface` 的真实节点、湿域和拓扑，以一批实际湿 quad 提交，并使用相同 Region 所有权。初建扫描一次；编辑更新脏区及有界索引，普通帧只更新材质时间。没有水体物理、逐格 Mesh 或逐帧岸线扫描。

生态复用现有枯树、残碑、魂灯等实例。阴雾使用固定 24 实例和不超过约 200 个候选采样点；地形/水域/阴气变化重评，魂影响按原景物节奏约 2 秒更新。关闭景物时停止该更新；静止 Region 不再逐帧重写实例。所有缓存归表现层，不写人口或 RNG。

`world/netherTerrainEdit.js` 暴露 `createNetherTerrainEditor(world)`，笔刷写真实 height/water/veg，并更新 type/qi、riverBase 与河岸缓存。撤销历史总预算 32 MiB，保留会话初态用于回滚。魂与鬼修的位置、活动目标复用 `netherLife` 的正式活动带判据；非法位置确定性迁移，不消费随机流。物品保持通行判据；无合法魂落点则整笔拒绝并回滚，不删除实体。

产品存档仍为 v11。旧档六层和生成期 temp/moist/riverBase 继续使用旧生成器。当前读档会从种子重建 riverBase，再覆盖已存 water，因此**候选生成和河道编辑不进入产品保存路径**。正式接入 D-N2 时必须先决定生成版本与 water/riverBase 的恢复策略；不能直接把试卷结果当产品档导出。
