# MLOD-0B 同模式确定性与长程等价

## 判据与运行入口

`node scripts/inkbox-mlod0b-equiv.mjs --days=30 --out=reports/mlod0b/equiv-30.json` 从已核验 SHA 的自然 100/400 年 v11/G8 存档分别恢复两条独立世界线，按相同 `dt=0.1/1/3` 推进。每次 `advanceWorld` 完成后，审计臂运行只读普查、旧村落社会口径和试验人口读者，并核对读前/读后的完整存档哈希。两臂每次合法提交比较完整 `serializeWorld` 和 runtime 的 JSON 字节，记录首个不同字段路径及每步世界/运行态哈希。只把同一输入、同一 `dt` 的分支做逐位对拍。输出按最多 30 步一次落盘，崩溃时保留最后已完成的验证窗口。

`node scripts/inkbox-mlod0b-equiv.mjs --days=360 --out=reports/mlod0b/equiv-360.json` 用相同方法覆盖 360 日。恢复世界本身含有的界层在完整存档哈希之内。浏览器新建的另外两界另由浏览器回归检验。

长程入口 `node scripts/inkbox-mlod0b-longrun.mjs --years=200 --dt=3 --seeds=20260914,73101,61003 --out=reports/mlod0b/longrun-200y.json`。资源允许时可按 `--seeds=20260914`、`--seeds=73101`、`--seeds=61003` 分成三个独立进程，各写独立 JSON，验收时须检查三份报告具有相同代码指纹及各自完整的 24,000 步，不能把不同版本证据拼在一起，每种子创建两份相同的旧版小世界，审计臂每步只读普查。两臂每个合法提交均完整序列化并逐字节比较。每年记录最后世界/运行态哈希、当年所有提交哈希的连续 SHA-256 和耗时，便于定位首次失败。跨进程重启不能无条件接续同一世界线，因为现有存档量化会改变未中断续跑轨迹；失败时保留已完成种子与首次不同的提交，不把恢复后重新跑的结果拼成连续证明。

## 状态及限制

初始一年试跑在种子 73101 上完成 120 步逐提交对拍。接口定稿前的长测预跑达到种子 20260914 第 7 年，已主动停止，不能计入最终门禁。正式结果以 `reports/mlod0b/longrun-200y.json` 的 `status=passed`、三条种子的 `completedSteps=24000` 和 200 条年度记录为准。上述条件全部达成前，状态为 **L0 LONGRUN INCOMPLETE**。自然档 30/360 日矩阵按各 JSON 中每个 case 的 `status` 与实际步数分别判定。

此检查证明诊断读取对同种子、同 `dt` 旧世界的逐提交状态无影响。它未证明新 L-C 人口模型、v11 未中断与读档后长期等价，后者已有恢复量化债务。现有旧版 `test:save-equivalence` 将恢复后 60 年分叉差异只列为观察项，不能据此给新旧存档续跑逐位等价结论。
