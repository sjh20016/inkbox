# E3S-P 研究验收

冻结 B 参考和两种执行方式在 180 个完整边界的 v11 存档、G8 runtime/RNG 及事件顺序一致。逐原子推进时完成 72409 次未提交隔离检查。补充的原生内核对拍比较原始 serializeWorld 对象、事件与工作计数，覆盖同一批自然 100/400 年窗口与 30 步受控三界。受控档由正式生成器建立。原始自然档只含凡间。

实际人物循环 30%/70% 处故障与内部 Store 已发布处故障均保留最后公开边界。恢复重放已完成账本。控制测试覆盖回执时间戳、同分片双命令事件、事件确认、故事/存档等待、取消、换代、暂停积压和 30/60 FPS 重放。E1C pass 在显式 return 和 throw 两种出口清理。

Edge Edg/157.0.4341.60 完成 Canvas 与 Intel UHD730 D3D11 WebGL 各三次 30 秒采样。每轮使用独立会话与同一份原始四百年 v11 输入。每轮至少有一个完成步经历多个真实 rAF 回调。核对了完整游戏日、目标水位、全部可信输入、已提交帧身份、安全存档与自有进程清理。每轮常态只有初始化一次 restore，显式保存前无全档序列化。另有两份单独的采样 CPU profile。

上游 Three 投影入口抽取后，原 E2R-a 源码接线断言仍匹配旧局部变量，首次远端 Fast Gate 因此失败。已修正断言，使它检查正式调用是否把 RenderFrame 传给共享投影。原实体列表绕过红例以及新增直接传入 World 红例均保留。实测期间的源实现未改。

生产化裁决见 WX_E3SP_DECISION.md，Worker 接口与验证范围见 WX_E3SP_WORKER_PROTOCOL.md。所有原始报告、失败样本、图片与清理记录随本地证据包交付。
