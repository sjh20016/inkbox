## 启动和试玩

```powershell
npm ci
npm run dev
```

打开 `http://127.0.0.1:4180/inkbox.html`，Three 使用 `?renderer=3d`。普通试玩优先选择 200×128 或 288×180；384×240 用于体验复查，512×320 留作专项压力场景。

1. 创世后让世界自然推进，从「值得关注」或地图检视进入真实人物命簿。
2. 打开「交战」观察近讯，查看同一人物的气血和养伤状态；「战斗墨痕」只控制表现。
3. 记挂人物，关闭命簿后从「记挂」再次观察。
4. 选择焚林，在有植被的地方落笔，再用检视观察此地；记录对照后推进时间，查看火灭与恢复。
5. 保存到槽位，新建另一世界，再读取原槽位；世界事实与记挂恢复，旧的会话地点对照不续接。
