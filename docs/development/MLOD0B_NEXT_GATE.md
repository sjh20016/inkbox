# MLOD-0B 向 MLOD-1A 的准入裁决

**现在可下发的首个切片是单村、只读的出生队列与迁户对账。正式人口权威继续由原 v11 世界持有。** 自然存档已经表明，同一日的实体归属、宗门缓存和面板发布代际回答三个不同的问题。把它们并成一个人数会立刻影响供养、战力或浏览时机。

## 最小施工切片

1. 从本包通过审查的提交开隔离研究分支。选取两档各一个有凡人、修士和可识别出生来源的聚落；保留输入 SHA、完整序列化基线及每界实际来源。输入缺出生地点或日期时单独记 unknown。
2. 在 `src/inkbox/sim/demography/` 的非权威投影旁新建研究模块。首次仅记录一个村的当前归属、实际修为、年龄资格、来源聚落和跨村流入/流出。以实际出生/迁户写者的前后行作为输入，记录同日先后次序。缺边界证据的事件标未解析。
3. 每次合法提交产出该村期初人数、出生、死亡、迁入、迁出及期末剩余，并同独立普查和旧经济谓词逐项核对。保留亲缘、在途、魂路、故事锁定者以及需按人精确回放者的真实身份。每次重新投影不得改变原实体或抽取 Life RNG。
4. 跑本包快速门禁、100/400 年自然档各跨一次月界，另用夹具覆盖同日出生后死亡、等量交换村籍、实际飞升离开凡界。持续检查逐次 v11+G8 字节与原始分支相同、区域余额守恒、各年龄/修为边际无差异、重复查询不新增人口。
5. 同时报告非空桶数、每个非空桶人数、无来源比例、建账与查询 P95。任何一处出现负余额、身份兼占、不可解释的差异或缓存在错误代际被复用，保留第一个差分并停止扩大范围。回退只需停止运行这个投影和研究观察器，无玩家存档转换步骤。

**独立的晋级决定。** 此切片可以作为新的隔离试验，真实凡人转入统计权威、匿名双亲、正式经济替换、v12 存档及跨界身份迁移仍需 L3 产品决策、事务证明与新旧生态比较。0B 同模式的长测衡量观察是否干扰世界，不能替代新模式的生态验收。

## 已取证的原生基线

运行 `node scripts/inkbox-mlod0b-baseline.mjs`。脚本从 Git 直接导出 #74 产品源码，分别用原版与本分支默认接口恢复真实档，逐次调用各自的 advanceWorld 和保存实现。两档初态和各十次三日推进，共 22 个检查点，v11 完整世界与 G8 runtime 的序列化字节逐一相同。[跨版本原始哈希](../../reports/mlod0b/baseline-default.json)

第 144000 日的真实差分保留如下。箭头从归属写入指向下一次原生统计所见的时点。

```mermaid
flowchart LR
  A["已存宗门缓存<br/>太白 599 / 72 · 扶桑 0 / 0"] --> B["当前实体归属<br/>太白 574 / 69 · 扶桑 25 / 3"]
  B --> C["恢复后首轮村庄同步<br/>宗门缓存仍沿用存档值"]
  C --> D["第 144003 日 stepSects 清点<br/>两宗缓存与实体归属逐项相同"]
```

图中每对数字是 followers / pop。已发生的改宗没有可回放的前一拍自然快照；源代码和当日存档能定位写后未重算的顺序，下一次清点则有实际逐阶段观测。
