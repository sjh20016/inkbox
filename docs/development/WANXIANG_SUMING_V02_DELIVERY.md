## 模块边界与可玩范围

wanxiang/catalog.js 与 content/ 保留四份设计的稳定内容；experienceTraits.js 是依据规格重建，不声称取得缺失 experience_content.json。profile.js、changes.js 管人物唯一 Profile 与权限、修订和命令幂等；effects.js、conditions.js、practice.js、damage.js、skills.js 通过已有学习、修炼、战斗、气血、治疗和感知接点消费。未知历史条件保持休眠。

inheritance.js 仅在 Life 原生出生提交后读取双亲，记录父母/血系/灵根/体质来源；不另造人口系统。experiences.js 在原生成功事实后抽取有限经历；encounters.js 保存赴事参与者和真实到达、有限资源与龙骨定脉。legend.js 绑定原物和原地点并经原生移动与真实工作结算。daoSeeds.js 只借附近活人的真实功法页，扣经验、锁借主、到期归还，期间修炼+5%，不永久复制功法。

存档维持 v11，通过 io/save.js 与 wanxiang/saveState.js 可选版本块保存三界 plane:id 的 Profile、世界运纪、经历、冷却和实验状态；校验未知字段和身份后才写入。UI 位于 mingpuView.js、characterCardView.js/css，命令由 characterRuntime.js/sandboxRuntime.js 接入。既有 artifacts、transit、world/planes 继续持有物品、交通和同世跨界的原始事实。打包与 CI 追加定向验证，保留原 Fast/Heavy 门禁。

真实运行增量仍有明确局限：真龙数值与定脉、修罗短期战意可消费，天凤涅槃和神王碎片未实现；18体质中时空、万劫、凡体藏奇、因果与引劫仍缺目标消费者；64卦只激活已有条件和轴组合。传奇、借页属于实验，不代表九祖整体实现。

## 实际验证与观察

万象定向套件覆盖目录、身份、三界存档、命令幂等、原生学习与战斗、赴事、付费疗伤、遗物继承和命簿编辑。最后一次修复了器修无法重新拾取刚放下的法宝，修复后 test:w01 和 test:wanxiang 均以 0 退出。旧 integration 失败记录保留，新聚合测试已覆盖该用例。收尾过程中的四项本地 Heavy 命令 regression、three-realms、save-equivalence、g1:longrun 均以 0 退出，运行时间早于最后的器修拾取修复。本地按 Fast 工作流逐项执行，器修拾取修复后重跑 W0.1 和万象并通过，余下渲染检查和 build 均通过。远端门禁须在 Draft PR 创建后运行。

Edge/CDP 软件光栅运行了桌面 Canvas、390×844 窄屏 Canvas 和桌面实际 Three。三个视口均打开同一真实人物的五页命簿，预览并提交体质，保存后清空该字段，读档后比对并确认恢复。10 项功能断言通过，各视口无控制台错误。Windows 进程归属查询超时，清理流程保留隔离 profile，进程退出码为 1。报告与截图在 reports/local/wanxiang/browser/。之后调整了命簿日期取整和窄屏标签换行，未重截这两处视觉改动。

小型凡间种子 73101 和 73102 每步推进 3 日，各运行 30 年。第 30 年分别有 141 和 120 名活人，全员有 Profile，体质持有者分别为 2 和 4 人，血系持有者各 2 人。末次采样均无修士或正在进行的赴事，自然记录未覆盖完整传承链。实验默认关闭。完整样本在 reports/local/wanxiang/profile/profile.json，命令为 npm run profile:wanxiang。尚缺成熟世界 GPU 数据和百年以上 Alpha 平衡对照。

## 回滚

本轮只在独立分支交付；不合并 main、不强推、不删除既有分支或 PR。停止实验可在新世界不加 wxExperiments=1，完整停用则从未启用 Alpha 的基线存档/新世界启动；已保存的传奇与借页状态不得靠删除存档块伪装安全撤销。需要退回代码时切回基线独立 checkout/工作树并使用对应旧存档，保留 Alpha 分支与存档备份供复查。不要把本候选新块强行交给不认识它的旧代码继续模拟。
