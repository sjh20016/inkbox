# WX-C 自然世界画像

三个固定种子20260914、73101、61003，正式小景创世→100年，包含30年截面；每个100年实际v11存档再以G8时钟与RNG恢复续跑30年。只推进凡间，没有附加上界/幽冥模拟，没有注入人物、血脉、经历或成功结果。最终候选复核结果的准确SHA保存在各JSON的`sha`及交付验收清单；不得把`preliminary/`目录当作最终证据。

复现：`npm run profile:wanxiang:c -- --seeds=20260914,73101,61003 --years=100 --follow=30 --out=reports/local/wanxiang-c/final`。也可各种子独立进程运行，分别指定输出目录。基线对照使用同一观察脚本的`--source=../inkbox-wanxiang-v02`，其源码树与b50623b相同。每3世界日采样并以梯形积分累计存活修士人年，不采用期末人数乘观察年数。

有货、合格、可达、愿意是每月扫描的累计观察次数，允许同一地点/人物重复出现，不能当成唯一人数。获派是正式赴事资格人数；到达按参与者去重，后续学习过程不重复计到达。成功/失败是结算次数，学习中不算成功。超时是情境次数，撤退是参与者次数，单位不同。原物/功法领取与经历授予也不是相同事件。`naturalCaves`来自逐步新地点ID观察，`generated`来自生成入口计数，两者若有差异原样保留，不强行对齐。

死亡均龄是观察区间实际死亡者的均值，不是出生队列预期寿命。各时间截面JSON含境界、64卦、体质、显隐血脉、性格、经历分布及每个宗门的供养/消耗/不足账本；每百修士年事实率见`factsPer100CultivatorYears`。末期主要自然体质为剑体、道胎、木体；没有人为补齐稀有体质持有者。三个种子均有三类性格。真龙的有限原物获得/稳定、潜隐家系和少量血脉显化可观察；不声称每种罕见血脉能力已自然触发。

机会漏斗说明：20260914续跑合格观察1406次但仅71次路线可达，是地理可达的明显瓶颈；73101自然阶段可达141次、愿意136次，瓶颈主要在机会匹配/行程，不能把损失全部归为角色不愿冒险。胆小退避没有完全封死重试；61003自然段与73101成熟段各观察到1次畏险恢复。

本组自然观测未出现恩义回助计数；真实付费援助及新恩义仍持续出现。已有恩义改变目标且有代价回助已在受控E验证，自然频率仍是未解决的玩法限制，不能用该夹具填自然统计。

性能与体量：最终每份JSON独立记录墙钟`elapsedMs`、用户+内核`cpuMs`及`cpuMsPerWorldYear`。这三个值受运行负载与不同世界内容影响，不用不同人口/机缘数量的原始耗时推断优化收益；同语义热路径对照另见[性能简报](./WX_C_EFFECT_PERF.md)。

受控命途A/B/C与新增D/E见[交付](./WX_C_DELIVERY.md)，与以上自然样本分开。
