## 接线方案（施工前）

- `world/transitGeography` 在查询时构建陆地/永久可航水域连通标签和少量岸接驳点，按需生成路径。临时洪水与小水坑不能产生远航港口；真实修士飞行独立检查能力与安全落点。缓存只在 WeakMap，terrain setter/重算/回滚/环境结算使其失效，不由渲染猜测地形变化。
- `sim/transit` 持有有上限的真实行程、载具和货物；出发扣源村，抵达才交付。`advanceWorld` 在 Life/自然事件后按同一游戏日推进；地理变化只重规划现有行程，受阻保留目的与货物。新交通不消费 Life.rng。
- `Life.stepEntity` 继续修炼、衰老、饥饿与受伤/死亡，在途人物只让出地面避险和即时移动权。不会删人造复制品，宗门、家庭、村庄身份仍来自原实体。
- v11 顶层增加可缺省的版本化 `transit.v=1` 块；实体数组不插列，路线/连通缓存/插值不存档。Canvas/Three 共用有限只读行程投影与书架控制；正式 `inkbox.html` 提供明确标注的“天道截海”初始实验，不另造模拟 demo。

## 已交付与规则

检查点1 `c49ea89` 提交通达性与正式失效出口；检查点2 `57af455` 接通真实旅程、Life/advance 和存档；检查点3 `6684a6a` 接通双端观察、正式实验及回归。来源 main 未修改。新运行时代码与输入全部走同一份 World，没有引入第三方框架或新PRNG。

永久水深至少0.02、连通水域至少48格且跨度至少8格才可产生有效岸接驳点；岸上接驳搜索最多16格、8个港口候选。水路搜索按出发水格复用BFS，路线缓存最多96条/16,384航点，临时洪水只读原永久水层。金丹（level20）起的真实存活修士可御空，不能无安全落点降落。陆路仍按原 `isWalkable` / 火势 / 墙体规则。整图连通缓存按需重建，未恢复持续水物理。

真实行程最多12个活动项与24个近期终态，ID单调增长；货物持有量、原载量、人物/载具引用、游戏日和取消/提粮意图入档，路线与缓存不入档。出发预留粮食不重复存在于源库存，先走到真实源村提粮，再接驳水路；到有效目标才交一次。自动派遣每30游戏日最多2船/4次实际路线查询，只匹配盈余源和缺粮目标。船速1格/日、飞行5格/日是集中MVP参数，不代表完整航运平衡。

取消/损失规则：尚未提粮且源村有效，退还预留粮；其他陆地中止记货损；水上弃航/船毁/目标失效会损失货物，无法安全站立的乘员置真实死亡条件，由旧Life清扫/入册。飞行不安全处取消先保留“待安全落地”意图，抵达安全目标再中止；不会把人瞬移返港。UI确认说明了真实风险。地形受阻保留同一目的、船号和货物，堵塞期间不会累积成恢复后的瞬移。

保存仍为v11，新增可缺省的 `transit.v=1` 独立块；没有向实体定长数组插列。缺块旧档正常载入；未知或损坏交通块拒绝导入/读取，让既有世界保护保留当前世界。没有实施全局RNG游标持久化。`sectEconomy` 原有宗门直供仍是简化机制，未声称整个经济已变成在途物流。

## 边界、后续与回退

岸接驳半径与水域阈值是本版的明确有限近似，尚无手工建港、复杂换乘、船员行业、浮力/海流/海战或全经济价格系统。真实旅程不等于取得宗门领土；宗门远征和直供迁移留T2。飞行无自由高度导航，也未重写全体人物AI或跨界身份转移。DPR2、其他GPU、密集宗门长期负载仍未封板；有限JS堆差不能证明无限耐久无泄漏。

T1可扩港口和贸易，T2接远征交付层，T3接载具/移动驻地；跨界身份与G8随机状态分别另行授权。本轮不改变关闭视界后裂隙冻结的规则，不引入#30/#37/#39内容。

候选回退可关闭Draft并继续使用main，或对本分支三个施工提交反向revert；不强推、不删除来源/证据、不重置main。退回不识别transit的旧版本前应保留新档备份：旧程序会忽略交通块，在途货物和任务不会继续结算，不能把这种降级当作无损回退。
