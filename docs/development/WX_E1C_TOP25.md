## Selected work and acceptance boundary

The scans are real CPU contributors, not the entire CPU budget: both profiles also contain readEffects catalog work, movement/target search, wanling live-effect source lookup, topology and restore/validation. Adjacent wanling/sect/worldgen hotspots remain outside this increment. Start with exact shared target lookup, then ordered mentor selection, then an independent live spatial query only if all mutation paths can be proved; preserve Life.grid and every returned conditions field. Count index construction, invalidation and fallback visits rather than moving the scan out of sight. The >=90% visit-reduction goal is experimental, not permission to exclude entities.

Before each production increment is accepted: fixed #66 oracle per axis with Object.is; unchanged sourceTag frequencies; natural100/400y 90d dt3 full world/runtime/RNG equality; exact fractional-step short windows; independent v11 restore forks; three-realm/death/identity boundaries. Final diagnostic-OFF ABBAABBA and actual Canvas/Three remain pending. No speedup, browser smoothness, rule change, dt=3 default, Worker or W6 long-run promotion is claimed by this list.
