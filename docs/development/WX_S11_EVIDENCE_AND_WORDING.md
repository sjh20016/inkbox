# WX-S1.1 证据、称谓与阅读准入

本规范补充 [WX-S1事实合同](./WX_S1_STORY_CONTRACT.md)，适用于后续 Storylet 内容。正式模拟事实是唯一权威；展示可以压缩，不得补造行动、支付、身份或结局。

## 结局与措辞

| outcome / 情形 | 玩家短语 | 所需证据 | 必须拒绝的反例 |
|---|---|---|---|
| success / failure | 再次实际探府成功／失败 | 后续同一人物、同一地点的 B 级 site-success / site-failure | 谨慎退避、当前畏险、地图上仍有洞府不证明再次到达 |
| paid-reciprocity | 首次有证回助／后来仍有回助 | A 级 natural-choice、报偿恩义、committed、真实正费用和非空结果 | 关系仍在、零支付、空结果不能完成；护关不等于目标突破 |
| recovered | 有正式恢复沿革 | 原聚落 B 级 recovered，且晚于最新灾损／荒废 | 更晚再灾、当前气血高、附近同名新村都不构成恢复 |
| abandoned | 原址荒废 | 同一原址 B 级 abandoned | 援助不等于已经重建，不能认附近新村为继承者 |
| provenance-known | 来历可考 | B 级 forged / spirit 等保留履历 | 仍在手中不等于发生过寻物旅程 |
| transfers-attested | 辗转有迹 | B 级 gained / inherited / found | 只有取得没有保留的遗落，不能宣告失而复得 |
| loss-and-recovery-attested | 曾失落后再为人取得 | 同原物、按正式履历顺序的 B 级 lost 后有取得 | 不证明原主寻找或亲自寻回；当前生产接口未保留 lost 时不得倒填 |
| current-location | 当前归属／现址可考 | 原物唯一归属与 C 级当前实况；卡片仍须有 A/B 履历 | 地面坐标不是历史遗落位置，不证明从未被取得 |
| ownership-unproven | 归属未能核实 | 库存与 ownerId 不一致 | 不猜偷盗、朽坏或任务完成 |
| 来源失去／引用过时 | 后续未可考／旧位面引用已过时 | 原名录缺失、冲突或跨界核验 | 不接同名、同号或新身体补齐历史 |

原物的通用 resolved 只用于有据历史摘录的展示预算，必须使用原物专用 outcome 短语。C/D 当前状态或机会不能独立构成行动结局。任何模板新增正式结果，都先声明所需的结构化 A/B 类型及其反例；不以自由文本关键字识别事务。

## 人物身份与来源分层

- 历史只存 helperKey、没有当时可靠本世号时，主要称谓为「旧日施助者（本世身份未可考）」。完整 key 和 identityKey 保留在可展开来源区。
- 当前同 ID、同名实体均不能证明历史身份。若未来来源保存当时称谓，可写「彼时记作某某」，仍不授权定位现在的身体。
- 位面、ID、本世与夺舍切点继续由原路由核验；未保留 incarnation 的历史关联按钮禁用，原因以可读文字显示。更换世界、人物或身体使已读导航权限失效。
- 对方后来死亡、飞升或夺舍，不撤销此前已完成且留存的回助；换主后对同身体的新支付不得记为报答原施助者。真实死者快照若没有 Profile，宁可不建卡，不能承诺重建完整传记。

## 节点与退化

单卡最多24来源／节点，主时间线默认最多12。纯函数 `selectVisibleStoryNodes` 只接受卡内匹配 key、日期相同的保留证据；保留首个来源、最初可证危机、最后来源和最新关键 A/B 转折，余位取最近节点。没有来源的节点被拒绝，不从 outcome 生成占位事件。

建卡的24来源上界也保留首因、末证与关键转折，防止结局在进入 UI 前就被截掉。折叠提示「中间另有 N 条已保留记录未在此展开」只计算本次投影内的实际保留节点；上游已淘汰数量未知。详情最多24条，能核查主时间线末证。不同日期按正式时间；同日只在同一正式有序历史中采用 sourceOrder，否则稳定键仅作展示排序，并说明「同日先后未可考」。

恩义先按正式日期、稳定回执键去重排序，最多展示首次和最新三次付费回助，lastEvidenceDay 覆盖最新保留回执。总数只能说「当前保留来源中至少有 N 次正式回助」，不能冒称一生累计。上游128条以外的历史不读取、不统计。

| 保留情况 | 允许呈现 |
|---|---|
| 首因与终证都在 | 闭环摘录，主要时间线可见正式终证日 |
| 只有首因 | 观察中／后续无证，不自动成功或失败 |
| 仅有中间履历 | 「留存史料可证……」，不猜原始起因 |
| A/B 来源全部失去 | 无卡或史料未可考，不用当前状态回填 |
| 当前身份不可访问 | 已证历史保留；后续和导航继续拒绝冒名 |

## 成本准入（后续内容必须遵守）

1. 每个人物每次模拟步新增叙事查询成本为 **0**。禁止给 stepEntity、Life.step、advanceWorld、readEffects、HUD 或 rAF 添加模板匹配、全人口扫描或故事编译。
2. 读取、筛选、渲染只处理既有有界记录；世界级 readWorldStories 仅供手工研究／导出，不能接入自动提示。原物唯一归属核查是主动查询时既有的三界库存检查，不声称任意人口下为常数成本。
3. 本包不增加事件订阅、RNG、保存字段、故事池、已读表或缓存队列。后续新故事仅在既有正式事务提交点或玩家主动读取时请求。
4. 未来若需要新行动，必须先具备真实行为消费者、正费用／成功与失败出口、身份和跨界规则、候选上界、性能预算及独立存档验收。不得从叙事文案直接写世界结果。
5. WX-S2新行动与人物旧约本包不接入；原物可靠遗失／归还事实应另在正式提交点立项，不能由观察层推导或改变 artifacts 保存形状。
6. 内容接入需有定向正反例、只读／存档／RNG证据与自然样本，并分开标记受控夹具。波动的毫秒统计作参考；确定性的容量与调用边界进入 CI。

渲染使用 textContent，不把来源字符串放进 innerHTML。390px证据长键可换行；说明和禁用原因可读。Tab可到来源 summary，Space原生开合来源且不触发游戏暂停；键盘处理只在阅读控件内拦截激活键传播，不改全局输入规则。
