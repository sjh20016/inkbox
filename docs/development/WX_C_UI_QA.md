# WX-C 命簿反馈与交互验证

命簿继续沿用命格、修持、因缘、经历、改命五页。普通目录仅提交命格身份；阶段、治疗计数、状态、恩义、道种不再作为普通目录编辑。多选性格和杂趣提交有限 ID 列表。人物草稿仍经控制器预览、提交，敕改另传 `authority: decree`。

显式敕改支持现有绝脉开脉、洗去已持有状态、切换已持有血脉显隐、敕赐初阶血脉。自由观世不收统一费用，初阶敕赐不授予自然稳定或遗传资格。普通操作会清除待提交敕改，敕改操作会替换待提交普通草稿，避免两种语义混杂。

经历页按有界正式事实记录展示日、引用、地点、参与者与结果；改命历史标明常规改命或天道敕改及传承、进行中事务影响。未记录成本不推断为零成本。机制静态检视中缺少行动上下文时显示“需等实际行动才能判定”，不宣称数值失效。

`node scripts/inkbox-wx-c-ui.mjs` 验证纯只读标签规则。真实 Canvas 桌面、窄屏及 Three 桌面的五页、普通改命、敕改、关闭重开、存读档由主代理最终浏览器报告补充；本文件不提前声明浏览器通过。初阶以外的自由血阶/纯度调节和任意阶段输入暂不向 UI 暴露。

浏览器复现脚本：`node scripts/inkbox-wx-c-browser.mjs`。入口保留 B 的 Canvas 1366×768、窄屏 390×844、Three 1366×768，并增加普通目录真实点击、预览后受控正式脱战事实、敕赐血脉、三种来源区分和真实存读档；软件 WebGL 仅验证功能。Browser plugin 不可用且 Tabbit 稳定启动器缺失，依据委托书允许的隔离 Edge/CDP 路径回退。最终结果写入 `reports/local/wanxiang-c/browser/acceptance.json`，本文件尚未宣称该脚本运行通过。
