# WX-D 自然世界与成熟样本

固定种子 `20260914`、`73101`、`61003`，与WX-C相同小景地图、正式创世及 `advanceWorld` 三日步长。各自从0推进100年，再读取真实v11检查点、恢复G8随机流和时钟续30年；首种子继续观察200和400年。观察器不注入人物、受伤、关系、资源、经历或成功结局。

`npm run profile:wanxiang:d` 生成逐十年人口、宗门供养、地点库存、可达抽样、关系、命卦、血脉、序列化和CPU证据，输出在忽略目录 `reports/local/wanxiang-d/profile/`。正式结果仅使用有明确源码SHA且无源码改动的记录；`preliminary/` 仅作诊断，不能替代最终验收。

画像记录的CPU包含观察器采样成本，`work` 是可选分阶段墙钟归属，life包含地点推进，不能相加当独占CPU。存档体积以UTF8 JSON字节计，浏览器压缩槽位另测。人物年以每3日存活修士数梯形积分计算，死亡均龄是观察区间实际死亡者均值，非出生队列寿命。

地点可达抽样在检查点对每个有内容洞府测试最多八名32格内真实境界合格修士的正式陆路；缺少本地资格者不等于全球不可达。候选/合格/可达是累计观察次数，正式派工/到达/结算分别计，不能混作唯一人数。分区域采用四象限，统计保留低频寻找失败与库存阻止。

## 成熟世界

20260914从真实100年存档恢复后到200年：794凡人、56修士、850份Profile；174洞府中29活跃、145沉寂；存档5.316MiB，地点JSON58622字节、Profile区块1241065字节。剩余龙骨/凤羽/神性碎片1/14/28份，不等于所有修士均有领取资格。29处活跃洞府均在本地抽样找到陆路。

130–200年进程CPU446.907秒，Life墙钟431681ms、地点2473ms、道途调度2139ms、路线验证5258ms，归属有重叠。主要成本在既有Life，未为长局重写核心算法。`perf-200y.json`用`ef690c55cc7c2a07fae3ddaf0cce936858bb1977`从真实200年检查点预热一次再独立恢复推进30日四次，最终世界/RNG摘要相同；CPU844–1063ms、墙钟718–804ms、序列化84–149ms。进程CPU含V8辅助线程，允许大于墙钟。

400年完成：1223凡人、138修士、1361份Profile，43个村落、8个宗门；260地点，其中237洞府为33活跃、204沉寂。期末有14份凤羽、33份神性碎片；传承、龙骨和地点关联原物库存为零。33处活跃洞府均在本地地理抽样找到陆路，此抽样不证明所有抽中人物具有稀有资源资格。存档9.607MiB，地点84020字节、Profile2493927字节；世界法宝6件、ID6个，Profile键唯一，所有检查点通过正式存档验证。

200–400年自然新增63洞府；独立新地点ID观测共237处（初始0、期末237），累计正式供给资格223次、`spawnCave`入口计数227次，覆盖入口不同，不以不同口径强行相减。最老洞府139032日，尚未达到144000日寿命；后续寿命临界修复不在此自然样本的触发区间，另由原C2C寿命断言验证。

## 复现与证据边界

Windows10.0.19045 x64 / Intel i3-12100 / Node24.11.1。三个初段独立进程并行，实际命令：

```text
node scripts/inkbox-wx-d-profile.mjs --seeds=20260914 --years=100 --follow=30 --long=400 --out=reports/local/wanxiang-d/profile
node scripts/inkbox-wx-d-profile.mjs --seeds=73101 --years=100 --follow=30 --long=0 --out=reports/local/wanxiang-d/profile/73101
node scripts/inkbox-wx-d-profile.mjs --seeds=61003 --years=100 --follow=30 --long=0 --out=reports/local/wanxiang-d/profile/61003
node scripts/inkbox-wx-d-perf.mjs --save=reports/local/wanxiang-d/profile/20260914-200y-save.json --out=reports/local/wanxiang-d/perf-200y.json
npm run profile:wanxiang:d:perf
```

本批观察器早期`sectSupply.resources`子对象未深拷贝，不作为逐十年库存证据；期末数值、平铺供养/消耗账和正式v11检查点可核。后续工具已深拷贝该字段，没有改写旧样本来源。本报告采用期末库存。

本批`milestones`和`choiceReasons`还会观测到转世后复制的`pastLife`历史，不能直接作独立行动完成数。例如200–400年报恩历史观测1129条，但正式回助实际919次；本报告与验收摘要采用后者。师承列仅为历史观测，完整长局独立师承完成总数未单列。后续观察器已排除前世历史复制；原始JSON保留原来源和真实局限，不伪填精确值。
