# 众生影账 · 架构裁决摘要

批准把只读影子普查和原有实体读取保留在同一候选中。允许在开发会话显式启用人口卡片对照。允许下发一个村的非权威出生队列试验。正式出生、觉醒、宗门供养、跨界和 v11 保存继续由原来的写者决定。合入裁决须同时阅读本候选最终 CI、长测及成本记录。

**分宗与人口所有权。** 第 144000 日太白剑宗存档为 599 名归属成员、72 名修士，当时逐人重算为 574/69；扶桑院·三从缓存 0/0 对应到实际 25/3。差额成对抵消。下一合法步的宗门清点才令两者各自追平。用总人数验收会漏掉这个错误，用新查到的人数回填旧缓存则可能改变供养、领地或战争。自然出生的双亲同样是实际实体：没有双亲的自然出生请求在正式 spawn 入口返回 0，连 RNG 游标也没有动。[阶段审计](MLOD0B_PHASE_AUDIT.md)

**最安全的读取点。** UI 在已启用的凡间会话读取最近一次成功发布的人口卡片。开启使用独立扫描核对供养口径，差异回退旧读；每次成功提交替换整代快照，半步或失败仍显示前一代。切回 legacy 可释放副本。模拟中的读者需要该阶段的当前事实，因此在隔离试验按调用现算。日期与实体数量都不能作为独立失效键。[端口决策](MLOD0B_PORT_DECISION.md)

**默认读取的性能。** 在同机每档五轮 ABBA 的 #74/候选配对中，100 年档单次 advance 的 P95 分别为 61.0/62.4 ms，400 年档为 253.2/278.5 ms。另一组 400 年样本在默认读取与显式 census 查询下为 236.0/260.8 ms。归档包含单次耗时及月界位置。并行长测的争用限制了微小差异的归因；当前数据不能据以承诺默认路径无回归，更不能宣布正式游戏加速。两档同次对拍的存档字节数相同。[性能报告](MLOD0B_PERFORMANCE.md)

**联合桶与来源。** 稀疏桶以所在世界区分同号村宗，保留实际修为、适育边界以及可从出生事实还原的时间队列。400 年档可用的自然村庄出生日期为 1,361 条。没有来源的旧行显式记 unknown。百万级负载实验检验按非空桶数工作的成本；真实的升降层、亲缘、战争与灾害仍需后续事务和生态证明。[联合桶裁决](MLOD0B_JOINT_BUCKET_DECISION.md)

**工程准入。** #74 和候选的默认运行在两档初态及各十个完整步上 v11+G8 完整字节相同。旧版存档结构测试通过，但它的未中断世界和恢复世界各续跑 60 年后分别有 922 和 954 个生灵，这条既有债务仍在。最终逐提交证明、未测范围、停止条件及下一包首个切片见[长测报告](MLOD0B_LONGRUN_EQUIVALENCE.md)和[施工切片](MLOD0B_NEXT_GATE.md)。
