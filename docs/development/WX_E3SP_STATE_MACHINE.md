Target day is a scalar watermark derived from the prior target anchor plus speed × base days/second × elapsed wall time. Pause first accrues the old speed to the control instant, then stops growth; in-flight work finishes and unpaid debt is retained. Resume reanchors on that retained watermark. At most one new step starts per runSlice; queue length is bounded, while numerical debt can grow if throughput is insufficient. rAF timestamp is measured separately; the demo uses performance.now for all watermark controls.

Fault/cancel closes the iterator, retains the old front and refuses saves, new progress and authority queries. Explicit recovery rechecks the private initial checkpoint hash, restores once and synchronously replays only completed step/command records. It verifies native command receipts. It does not claim arbitrary rollback, and replay may block this research main thread. The 4096-record limit fails closed pending explicit save/replacement. Control operation epochs prevent late SHA continuations from reviving disposed/replaced sessions. Pending save/story operations are rejected on replacement/fault.
