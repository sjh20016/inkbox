# WX-E1 deterministic cost guard

`npm run test:wx-e1` checks deterministic work counters, not elapsed time. It creates controlled actor/world fixtures at N=500, 1000, 1500, and 2500, initializes each actor profile, enables `enableWorkMetrics(world, true, {timing:false})`, and invokes production `readEffects` with a catalog hexagram that activates `three_allies_near` plus a shared-insight bond targeting the last entity. These are synthetic fixtures, not natural-world or performance measurements. The gate checks the real peer/shared scan counts, exact active visits against the measured actor's `traits.length + states.length`, and the W2 active-list requirement that repeated arrays/copies remain zero.

The guard rejects unregistered metric keys, so a newly instrumented scan cannot silently escape an explicit budget review. Controlled red cases mutate a measured counter to an over-budget value and inject an unknown scan counter; both fail. Timing is disabled and there are no timing assertions.

The guard complements, and does not replace, `npm run test:wx-e0`: E0 keeps its historical baseline inventory, protected anchors, and changed-source failure behavior. E0 source anchors detect edits to protected transitive consumers; they are human review anchors, not a general loop detector, and do not promise discovery of arbitrary loops inserted into unprotected old files. The registry adds protection entries for `conditions.js`, `experiences.js`, `cultivation.js`, `practice.js`, and `daoActivities.js`. On 2026-11-09 an independent reviewer audited all nine modified production source files and verified the frozen oracle against #65; the coordinator then deliberately pinned their LF-normalized hashes. No test automatically updates anchors. The review found strong retention of historical actors in diagnostics; it was fixed with WeakSet and reviewed before approval.

`readEffects` has transitive population-scaled work. Peer and shared-bond reads can scan up to N entities per invocation, so aggregate cost is O(readEffects calls * N), not a one-entity bound. This guard bounds metric totals for its synthetic fixtures; it does not claim to prove asymptotic behavior for arbitrary code.
