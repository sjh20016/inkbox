# WX-D 社会行为

基线 `eb99cf5d`。施工范围：`wanxiang/opportunities.js` 与 `sim/daoActivities.js`，沿用万灵任务、正式移动、治疗与经历处理器。

## 行动

- 每 30 日的现有道途调度中，只读取修士自身有界恩义与师徒关系。有效恩义必须同界、未休眠、未过期、指向当前活人；师徒关系必须仍在正式关系 Map 中。
- 目标有真实伤势时选择疗伤；临近正式突破经验门槛时可选择付费护关。实际地点须在 24 格内且有正式陆路路径，途中不抢占正式远行或洞府行程。
- 社会任务保存在既有 `wanling.jobs`，记录目标转生身份、意图、关系、路点、起始日与结果。过期、死亡、关系消失、身份变化、远行接管均终止。相同对象 720 日内不重复建立社会任务。
- 地形版本变化、目标移格、读档首次推进或90日届满时，有界重算正式陆路，失败即撤销。护关先检查有效状态容量，提交后核对真实护关状态；状态已满不扣款、不写成功事实。
- 陆路规划的地形版本、目标格和规划日只放在运行期 WeakMap；读档首次推进、目标移格、地形变更或 90 日后重新规划。若失去合法路径，任务明确撤销。
- 疗伤经 `readEffects(...).healing` 和 `healingReceived` 计算，实际恢复气血后才写 `healed` 事实。护关经 `gate-aid` 事实产生限时 `alchemy_guard`，由正式突破消费。两者均先支付宗门灵石或施助者气血，不生成资源。
- 护关在支付前检查受助者是否尚有状态容量；事实提交后确认限时护关状态实际存在。满状态时不支付、不记成功，逾期后以失败结案。
- 人物历史 `natural-choice` 记录原因、对象、位置、具体支付方式与数量、实际结果。万灵任务也保存终态和摘要。成功回助计入 `reciprocity`；它由真实完成触发。
- 丹修正式活动对同宗受伤者有轻微选择倾向，前提是所属宗门确有可支付灵石。行动结算从宗门扣除灵石；宗门断供后仍可由施助者承担自身气血，双方均无力时治疗不发生。同宗照护另记原因、费用与实效。

## 验证边界

定向脚本 `node scripts/inkbox-wx-d-social.mjs` 从正式丹修活动触发受助，随后检查恩义回访疗伤、代价、历史、护关、任务存档恢复、休眠撤销、无力支付失败、超时、命卦援助偏好、同宗照护与断供。自然长期频率和宗门经济表现由主线画像统计，不将定向脚本计作自然发生率。
