## 集成修复与保护

- 结构线在容量内复用 attribute/typed array，仅上传有效段；扩容先释放旧几何的 GPU 绑定，最终释放不触碰共享地形几何。
- 线刻由高度纹理 R 通道选择与 G5 相同的 V2 动态对角线，再按 G 通道的实际三角面插值；旧世界保留 BC 对角，避免非共面四边形上浮线或埋线。
- 环境轮廓随风格、实例数量和 LOD 即时开关；不需要轮廓时直接跳过提交。换世界清理三界装饰背景，避免沿用旧种子纹理。
- 创世/读档/导入沿用原按钮与 QOL 确认处理器，菜单仅负责表示和请求，打开时暂停、关闭时恢复。肖像取正式 `identity.key`，不读取姓名猜身份，不消耗 RNG；卜算子 SVG 保留 A1 Viewer 的真实入口。
- 命簿保留原 G1 节点和处理器，移至独立层叠位置；窄屏观察抽屉、帮助、创世菜单与命簿按当前顶层窗口管理焦点和按键，相机在窗口打开时清空已按住的移动键。
- 真实窄屏验收修正 Tab 边界：非当前命簿分卷的 `tabindex=-1` 按钮不参与循环，避免从最后一项跳到页面背景。肖像按独立发色索引取色，所有八种发型均覆盖合法颜色回归。
- 默认 Canvas 不提前加载 Three；「立体沙盘」和 URL 的 3D 入口共用按需加载函数，并发请求复用同一 Adapter，保留当前世界。
- 性能调查后仅简化几像素远景树冠的 LOD2 母版，近中景不变；线刻提取及临时打包按每帧约 3 ms 推进，完整提交后复用原 GPU 缓冲。同步入口使用同一数值算法，四组原始结构结果哈希保持一致。
- 分帧任务对世界、世代、风格和区域检查有效性；区域变化立即隐藏旧结构线，防止等待新结果时越界显示。高度纹理始终由正式地形更新，现有笔画的贴地不等待拓扑重建。
- 植被贴地时的峭壁隐藏翻转只重写受影响实例的完整矩阵，其余树仅更新实际变化的 Y；完整与局部路径共用变换公式。山海林候选区额外覆盖一节点的坡度探针范围，单格编辑、隐藏与恢复均与全量构建逐值一致，不再因一棵树变化重写整林及颜色。

`test:g5` 验证 GPU/CPU 地形、水面湿域、植被更新及拾取一致性；`test:r1` 验证真实地形纹理/索引、线刻生命周期、自然雕刻事务和锁定范围。水文、热蚀可能使运行中的旧雕刻事务冲突，因此精确撤销/重做在暂停状态验收，正常演进另行观察；不绕过正式冲突保护。
