正式 A 阶段用同硬件记录了 Canvas 总览 4.78–4.93 日/秒和 Three 总览 5.94–5.98 日/秒。研究 C 的场景更小，使用原始凡间档、固定 3 日和稍新的 Edge 构建。两组数据说明待解决的性能缺口。正式全场景提升幅度仍需等口径验证。

Worker 应持有单一私有模拟，接收可合并的目标日期与优先控制命令，在完整边界发布有限 DTO、事件和地形脏块。B 的 G1 借用引用、Three 场景及 Canvas 其他层仍需迁移。Worker 有机会解除模拟吞吐对显示帧的依赖，仍需实测传输、渲染和权威延迟。固定步长策略须单独通过 W6。
