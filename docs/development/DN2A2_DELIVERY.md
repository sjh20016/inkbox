## 运行与最终方向

`npm ci`，然后 `npm run dev -- --port 4264`，打开 [独立展厅](../../research/nether-strata/index.html)。本地预览地址为 `http://127.0.0.1:4264/research/nether-strata/index.html`。默认 B「苍墨山水」与淡焰；A/C 保留可选。新地貌、旧 D-N2A 和 D-N1 可独立选择，旧版四种墨焰预设保留在折叠菜单。`?version=strata&look=inkflame` 重访 D-N2A.1。

按用户追加的三张参考图及后续指示，最终采用**峰顶积墨、较暗地面、少量崖缘枯枝、上黑下浅的灰色渐变**。先前纯黑方案保留为底色选项，默认改为墨灰渐境；背景与世界外壁融色。受光岩肩仍保留骨白，低层保留暗隙与局部白焰。旧纸境用于历史对照，默认不再使用重复的圆山背景。

「纯大块墨色」关闭细线、魂焰、虚白底与可选景物；表现时钟停住，相机仍可操作。细笔、魂焰 off/static/flow、淡焰/游焰/狱焰、画外景物和悬浮构件均有独立控制。「留存此境机位」把种子、画幅、风格、相机和主要表现选项写入地址栏，可复制链接重访。

## 形态、笔墨与魂焰

原平台感来自多边形的恒定抬升，窄岩片来自台地与裂谷、深渊相减；灰白感还来自稀薄的平地材质覆盖。改动按几何、静态墨色、细笔、魂焰的顺序完成。

| 范围 | 实际实现 |
| --- | --- |
| 主岩骨与台地 | 同一个候选生成器增加显式 `ink-art` 入口；宽主脊、顶部有限起伏、少量大崩口、不完整崖缘及偏置岩肩，保留主断层高差 |
| 薄岩片 | 两次有限邻域检查，只降低缺少横向支持的高窄残片；不对全图模糊，合成宽墙与有宽度岩柱保持 |
| 黄泉坡肩 | 水域宽度仍约 2.8 格，岸坡混合真正延伸到 6.5 格或随画幅调整的外沿，修复原来计算宽、应用窄的硬切 |
| 深渊层次 | 部分深渊边段保留次级岩肩，仍是单值高度场，没有地下可行走面 |
| 大块墨色 | 高程、宽域坡度与朝向、局部凹陷、阴气和湿域共同决定积墨；峰顶与阴面压重，干地墨层获得完整覆盖，暗谷不再整体漂白 |
| 三级笔触 | 稀少主墨骨、非等距的断续层理、近景方向性枯笔；替换圆斑式飞白，细纹随观察尺度淡出，旧连续花边线减少 |
| 阴焰 | 暗谷中的局部负形与细长火舌；世界坐标根部保持，低频上移并局部翻卷，默认淡焰，颜色保持冷白 |
| 枯枝与景物 | 崖缘/岩肩优先布局，仍用原十二株枯木的实例预算；每株增加八段细枝，不增加 Mesh 或新生态实体 |

四画幅 × 五种子下，以候选原始高程计，新岸线相邻格点平均高差为 **.009～.052**，旧版为 **.127～.286**；黄泉保持四邻单连通。旧 D-N2A 中堂种子 0/1/42 的高程与 `034784d` 字节夹具一致。细长残片修复、有限高度、真实宽墙/岩柱保留及全部生成字段确定性见 [技术验收](./dn2a2/acceptance.json)。

## A / B / C

三者共用地貌、材质、遮罩和魂焰批次，通过参数变化，不复制三份 Shader。

| 候选 | 画面倾向 | 用途 |
| --- | --- | --- |
| A 焦墨绝壁 | 积墨对比更强，主崖阴面最重，骨白岩肩明确 | 特殊狱境 |
| B 苍墨山水 | 主墨骨与灰墨过渡较均衡，峰顶压重，留白较克制 | 默认推荐 |
| C 白狱魂焰 | 上部保留重量，下层局部虚白与魂焰更强 | 无间深渊等特殊地域 |

保留 B 为默认：主崖、岩肩和暗谷较容易同时辨认；A 在一些近景过重，C 会牺牲部分底部细节。该选择是当前实机候选的推荐，不代替用户最终美术裁决。

16 个最终窗口的 >50ms RAF 间隔均为 0。几何修形、结构线收束及景物按新地形重新派生，都会改变总场景计数，因此不能把相对旧版的全部差值归因于魂焰。隔离比较新版「加笔触」与「完整」：魂焰增加 **1 draw / 1 geometry / 576 三角面 / 0 额外纹理**，实例上限 24，对应十二处局部渗口的交叉弯曲细片，没有铺满深渊的大面。

RGBA8 分类纹理共用原 D-N2A.1 所有权，中堂 207,360 字节、广卷 655,360 字节；灰渐变只缓存一张 32×512、无 mipmap 的纹理，基图 64 KiB，不逐帧重绘。空闲帧新增全图分类扫描、拓扑重建、遮罩上传和实例重写均为 0。关闭魂焰释放薄片，不再写时间 uniform；全部关闭释放分类场。World 替换、Region 与整层释放有定向验证。

这些是预热后的只读展厅样本，未测 GPU timer query；CPU 提交不是 GPU 执行时间，也不代表稳定 60 FPS、完整游戏性能封板或多设备结论。前一轮完整样本有明显时间长尾，原数据留在 ignored 报告目录，不能用本轮较好窗口倒推所有运行环境都稳定。
