# V1 · 山海入画 — 垂直切片交付说明

分支：`art/v1-shanhai-rhua`（基于 main `c45f9be`，未合并 main）

## 运行入口
- `npm start` → `http://127.0.0.1:4180/inkbox.html?renderer=3d`（默认即 V1 山海入画档 `art=shanhai-v1`）
- 对照：`&art=realm-style-v1`（旧三界风格档）、`&art=off`（原始基线）
- 关闭画中景：`&scenery=off`，或 3D 工具栏「画中景」复选框
- 切界：`&plane=upper` / `&plane=nether`；视界：左侧「视界」工具框选局部揭开
- 推荐视角：工具栏「观山」或快捷键 **R**（远 / 中 / 近三档循环）

## 方向（据最新参考调整）
放弃 Blender 式厚体积重明暗，走「轻盈线描写意」：减阴影、淡彩稀释向纸色、山体加断续皴线与山脊墨线、峰顶留白、云脚轻雾；
凡界淡彩青绿 + 黛灰屋顶（非纯黑）；上界青绿泥金 + 云海浮岛；幽冥白描淡墨 + 焦墨 + 少量朱红（红月 / 魂灯）。

## 纯装饰 / 占位清单（全部不可拾取、不参与通行、不写存档）
- ShanhaiSceneryLayer 全部景观（raycast noop，遇聚落让位，随视界 Region 裁切）
- ShanhaiAtmosphere：背景画幅、远山、云底、上界浮岛小殿、幽冥断岩残碑（均在地图外）
- RealmVeilRim：揭卷纸边与界印 Sprite
- BreakthroughSeal：法印 Sprite（只读既有突破条目）
- InkOutline：墨线外壳（共享 instanceMatrix，挂在源网格下，raycast noop）
- 占位性质：景观为程序化低模，非最终美术资产；法印字为系统字体，非篆刻手稿
