# V1.1 · 山海成卷，万象随形 —— 交付说明

分支：`art/v1.1-shanhai-juan`（基于 V1 `d87d528`，未合并 main）。全部改动仅在表现层（render3d），不改 World / 存档 / RNG（purity 测试 digest 不变）。

## 1. 视觉变化
- **山河**：地形着色重写为「平 · 丘 · 陡 · 崖」四级笔法：平地淡彩留纸，丘陵披麻皴 + 断续勾线，陡坡石青绿透赭，崖面赭石打底 + 斧劈墨块与裂线，崖顶唇边留白、山脊墨线、峰顶留白；受光分三档（受光 / 中间 / 背光，边界随低频笔势游走）。
- **植被**：二十面体树团替换为 `ShanhaiFlora`：阔叶团簇 + 松，成片色块、墨线外壳；崖面不长树，聚落与景观周围自动让景。
- **建筑**：白墙黛瓦调色、三档平涂（背光柔化混冷），墨线孪生外壳统一闭合。
- **人物 / 异兽**：修士沿用 g26 三渲二 + 墨线；异兽新增三渲二着色（三档 + 冷影 + 纸色逆光），随「墨线」开关。
- **三界**：凡界温润（雾 .26）；上界矿彩深化（新增 `mineral` 罩染：石青石绿厚罩，赭石只留崖脚，饱和提升）+ 倒悬山浮岛；幽冥提供 A 版画 / B 焦墨两版。
- **组合景观（占位）**：山居 hermitage、云台仙殿 terrace（上界浮岛主岛）、幽冥遗迹 remnant；浮岛卫星小岛带碑 / 松。

## 2. 新美术方法
- 自适应高程分层：`updateShanhaiBand` 按 p97 高度重采样（改造后 ≥1.2s、10% 滞回、平滑过渡），任何地貌 / 改造都落在同一套青绿-赭石层次内。
- 屏幕密度收敛：皴、勾线、斧劈、裂线按像素间距淡出（<~7px 不画），远景不糊、近景不过密。
- 墨线外壳（inverted hull）统一用于树、建筑、景观、浮岛。
- 景观固定容量槽位 + 稳定 key 重排；占地 zones 下发植被做让景。

## 3. 被替换的旧方案
V1 二十面体树团 → Flora 团簇/松；V1 倒三角 / 锥形浮岛 → 倒悬山浮岛（平顶、三折内收、顶点色草绿→赭→石青→纸色淡出）；固定高程带 → 自适应分层；平面法线墨线（不闭合）→ 外壳墨线；hall 浮殿 → terrace 云台仙殿；背景倒三角远岛 → 倒悬山剪影。

## 4. 动态地形适配解决的问题
- 抬山 / 削山 / 山脊 / 平整 / 盆地 / 近水后：崖面树自动隐藏；景观 0.4s 去抖随地形重排、五点最低采样落地（不再浮空 / 埋地）；景观让树；分层随高度自动重算（V1 尖峰地形整体发灰）；人造峭壁上出现赭石崖面 + 斧劈而非拉伸色带。
- 撤销 / 重做 / 存读档：高度差 0，渲染射线与 elevation 0 偏差。
- 修复：大幅山脊改造后偶发跨图水面三角楔形（WaterGpuSurface 多段 updateRange 改为整体上传）；V1 浮岛 clearBase 嵌套几何泄漏。
- 资源：视界开关 ×6、世界往返切换，geometry / texture / program 计数不增长。

## 5. 幽冥 A / B 选择
默认 **B 焦墨**（干笔飞白打散边界，融合 A 的黑白结构）；`?nether=print` 切 A 版画，`?nether=v1` 回退 V1。

## 6. 验证

## 7. 局限
GOLDEN_A 尖峰几何仍有面片感；竖崖几何是高度场拉伸（只靠着色补救）；人物仅着色强化、未重建模；水面偏淡；幽冥远景略斑驳；牌坊判据偏严在 GOLDEN_A 中不出现；景观为占位造型。
