# V1.2《山海归素：程序化山水的视觉秩序重建》设计说明

分支：`art/v1.2-shanhai-guisu`（基于 V1.1 `a565679`），未合并 main。

## 1. 方向选择（A/B/C 小规模对比）
对比图：`shots/cmp_ABC.jpg`（行：A 旧版气质 `?art=realm-style-v1` / B V1.1 / C V1.2；列：远、中、近、村落）。
- **A 旧版气质**：低饱和暖灰、整块山体、舒适，但缺少 V1.1 的分层、让景与三界差异。
- **B V1.1**：技术完整，但逐片硬明暗 + 等高勾线 + 竖向斧劈 + 裂线 + 高饱和青绿，山体碎、噪、"石笋墙"。
- **C 融合（推荐并实装）**：A 的色面与整体感 + V1.1 的全部结构技术；笔触只在需要的地方出现。

## 2. 保留的旧版（Codex）特点
低饱和暖灰山体、柔和灰绿植被、淡青灰水面、整块大形、明暗软过渡、山脚雾气留白。

## 3. V1.1 技术：保留 / 调整
- **保留**：自适应分层与远中近 LOD、景观重排与建筑让景、ShanhaiFlora 林相、上界浮岛、幽冥双版（版画/焦墨）、资源修复、单源 VisualElevation。
- **调整**：
  - 几何（不完全依赖材质的改善）：`VisualElevation` 二次项 38→22，山顶约低 17%，高处格间坡度约缓 23%，削弱尖峰/石笋；单源函数，网格/贴地/拾取/水/相机自动一致。
  - 山体材质：颜色与明暗只读宽域坡度/法线；软三档明暗 + 冷暖塑形；按屏幕像素密度给笔触预算；皴只出现在陡面明暗交界与背光；斧劈只给大崖；删除等高勾线与裂线；近景陡面加水平岩层；崖面消除竖向拉伸；墨线改为宽域剪影 + 主脊；山脚雾带。
  - 配色：凡界暖灰/灰绿/淡青灰；上界淡青灰蓝 + 浅紫阴影，取消饱和提升；幽冥大块留白 + 焦墨集中于背光面、大崖与轮廓。
  - 植被：林相低频成片、远景收敛为单色林面、墨线随屏幕尺寸淡出，树尺度 0.86→0.78。
  - 建筑/人物/异兽：墨线按屏幕尺寸淡出、墨色暖化，避免远处"黑点噪声"。
  - 上界浮岛：只主岛有仙殿，卫星岛减装饰，云裙放大 + 云托与云融合。

## 4. 外部参考提炼的可执行原则
1. 大形先于笔触：先保证体块明暗，再加皴。
2. 笔触集中在轮廓与明暗交界，受光面留白。
3. 山脚留白、以雾分层（远淡近浓）。
4. 屏幕密度预算：笔触/墨线随像素尺寸出现与淡出。
5. 有限调色板 + 饱和度层级（近处略饱和，远处趋灰）。
6. 林成色块，不画单株。
7. 远景简化为色面剪影。

## 5. 为何更舒适
信息层级清楚：大形 → 明暗 → 少量笔触；高频噪声（等高线、裂线、竖向斧劈）被移除；色彩低饱和且同一色相族；远景干净、近景才有细节，视线有落点。
