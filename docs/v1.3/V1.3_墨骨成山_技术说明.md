# V1.3《墨骨成山》技术说明

分支 `art/v1.3-mogu-chengshan`（基于 V1.2 `1f2b97e`）。对照截图见 `shots/`，性能见 `perf_v13.txt`。

## 1. 线刻路线
参考 Blender Freestyle / Grease Pencil Line Art 的思路：**线 = 几何特征（轮廓、折痕、山脊）的投影，而不是贴图**。
项目禁用 RenderTarget / EffectComposer，且全屏法线-深度边缘检测在远景会闪、成本也高，所以采用两层实时方案：

| 层 | 做法 | 空间逻辑 |
|---|---|---|
| 轮廓（Contour/Silhouette） | 与地形共享几何的**背面外扩壳**（inverted hull），GPU 从同一 heightTexture 位移；屏幕空间恒定像素外扩；平滑法线仍正对镜头的碎折面丢弃 | 由深度缓冲天然遮挡；随视角实时变化；缩放线宽恒定不闪 |
| 结构线（Ridge/Valley/Cliff/皴笔） | CPU 对高度场做多尺度平滑 + Hessian 主曲率 + 非极大抑制，8 向连链、去短、Chaikin 平滑、权重归一；渲染为屏幕空间带状四边形，GPU 现采高度 | 线就长在真实山脊/谷线/崖顶上；雕刻后 180 ms 重建并贴地跟随；远景按权重门限只留主笔 |

骨白填充在 `PigmentTerrainMaterial` 内完成（同一 pass），远景雾中线条一起淡出。

## 2. 幽冥 A / B / C 与推荐
- **A 极简轮廓**：只有外轮廓 + 主脊。最干净，但近景缺结构，山体发"平"。
- **B 轮廓 + 结构线**：加谷线、崖顶折线。可读性最好、最克制。
- **C 完整线刻**：再加焦墨/干笔、粗细变化、灰白过渡、近景顺坡皴笔（皴笔仅在近景出现）。

**推荐并默认 C**：中景最像"线描山水"，近景有皴笔支撑体积，远景经门限自动收敛到接近 B。若要更简洁可切 B。
URL 调试开关：`?nether=line-a|line-b|line-c|v12`（v12 = V1.2 原版墨色），`?lines=off` 关闭三界线刻，`?sculpt=classic` 恢复 V1.2 雕刻。

## 3. 三界
三界共享同一 `TerrainLineArt`（每个 PlaneStage 一份），只通过 `ShanhaiStyle` 参数区分：
- 幽冥：骨白 + 焦墨线（主表现语言）。
- 凡界：淡薄墨轮廓（α≈0.42）+ 稀疏主脊，保留 V1.2 的青绿与舒适度。
- 上界：冷灰蓝细线（α≈0.40，断续 0.35），保持轻盈。

## 4. 山体形态（平顶高墙）
原因：V1.2 抬升是"线性累加 + 1.0 截断"，强笔反复叠加 ⇒ 顶部被削成平台、四周近乎垂直。
V1.3 在真实高度场上改（拾取、贴地、水体、存档、撤销都直接继承）：
1. **穹顶天花**：单笔最大高度 = 1 − 0.30(d/R)²，中心可到顶，边缘低 ⇒ 峰而非台。
2. **软饱和**：越接近天花增速越缓（最低 20%），峰顶收成圆穹。
3. **坡肩裙坡（talus apron）**：新增量沿 8 邻域按休止角 0.06/格向外坍落，衰减 0.88/格，外扩 1.2R+3；只传播本笔增量，不改动其他地形。
4. 压地/盆地对称处理成碗底。
`flatten/smooth` 与核心 `sculpt()` 默认仍是经典语义（契约测试不变），只有 UI 画笔路径启用自然模式；撤销记录的是逐格前后值，与模式无关；RNG 无改动。

实测（同一组 18 笔强改造，两个种子）：峰顶平台格 103/108 → 21/22；最大格间坡度 0.438/0.414 → 0.110/0.102。

## 5. 中长期山脉生成建议
1. **主次山脊骨架**：先生成主脊折线（分形中点位移/样条），再沿法向衍生次脊，骨架即结构线来源，线刻可直接复用。
2. **距离场成形**：高度 = f(到骨架距离) 叠加剖面曲线（尖峰/穹顶/方山三类），天然无平顶墙。
3. **多尺度峰群**：主峰 + 卫峰按骨架采样，指数衰减的高度层级，形成"主宾揖让"。
4. **谷地与盆地**：骨架之间做距离场谷线，结合流量累积生成盆地、平原与河道。
5. **轻量侵蚀**：热侵蚀（talus，已在笔刷中验证）+ 少量水力侵蚀迭代，离线于生成阶段执行。
6. **地貌类型参数化**：峰林、方山、丘陵、断崖台地作为预设，供生成与笔刷共享。

## 6. 未解决问题与建议
- 性能只在 SwiftShader 下测得（线刻层 +2.3%~5.5%）；需在真实 GPU（集显/移动端）复测。
- 轮廓壳在极低视角、极陡的单格尖刺处偶有短断线；结构线重建期间（≤180 ms）线条沿用旧链，大幅雕刻时可能短暂错位。
- 幽冥近景的骨白填充仍偏平，可考虑按坡向再加一层淡墨渲染。
- 自然雕刻的单笔成本约为经典的 3–5 倍（仍 <5 ms）；超大半径笔刷建议做时间片。
- `test:render3d:m2c` 在 V1.2 基线已失败（预设名单未含 `shanhai-v1`），本版未改动。
