# 中国画传统配色与特殊色彩：游戏开发 / AI 美术参考包 v1.0

## 定位
这是一套“数字化生产参考”，不是文物颜料色度标准。传统颜料没有唯一 HEX。石青、石绿尤其会因颗粒级别、胶、水、纸绢、叠染与老化产生明显差异。本包中的 HEX/RGB 是为了让游戏引擎、前端、Shader、概念图 AI、贴图 AI 能共享一套稳定的色彩锚点。

## 建议使用层级
- 第 1 层：纸 / 绢底色
- 第 2 层：墨骨（焦、浓、重、淡、清）
- 第 3 层：透明水色（花青、藤黄、胭脂、赭石及综合色）
- 第 4 层：矿物重彩（石青、石绿、朱砂、石黄等）
- 第 5 层：特殊点睛（泥金、泥银、云母白）

## 最重要的画面原则
- 墨是结构，色是关系：先建立黑白层级，再加色，不要让颜色盖掉结构。
- 纸色本身就是一种颜色。水、雾、雪、白花、天空经常应由留白承担主体。
- 矿物色（石青、石绿、朱砂等）更适合作为覆盖性强、颗粒感明显、局部重彩的颜色。
- 植物/水色（花青、藤黄、胭脂等）更适合透明罩染、渐层与综合色。
- 同一种颜色至少保留深/中/浅三个层级。石青石绿尤其不要只用一个HEX。
- 避免纯数字原色：不用 #0000FF 代替花青/石青，不用 #00FF00 代替石绿，不用 #FF0000 代替朱砂。
- 大面积背景优先低饱和纸色、墨色、赭色；高彩度石色只在视觉中心或身份符号处使用。
- 金色最好控制为线、边、纹、器物高光，而非大面积黄色填充。
- 远景统一向纸色和清墨靠拢，降低饱和度、对比度和细节密度。
- 游戏PBR中可以保留材质明暗，但基础色仍应服从国画色域；避免金属、塑料高光破坏纸本气质。

## 常用调和逻辑
- **草绿**：花青 70 + 藤黄 30；用途：一般叶面、草坡。常见现代国画教学比例，实际按画面调整
- **汁绿**：藤黄 80 + 花青 15 + 朱磦 5；用途：嫩叶、反叶、瓜果嫩绿。常见现代国画教学比例
- **老绿**：草绿 + 少量墨 或 少量胭脂；用途：老叶、暗叶。避免做成纯黑绿
- **墨青**：花青 + 墨；用途：夜色、阴山、瓦面、水暗部。保持青意，不要变成纯黑
- **赭墨**：赭石 + 墨；用途：树干、石缝、旧木。近景可重，远景降低对比
- **赭黄**：藤黄 + 赭石；用途：土坡、暖山、木构亮部。适合浅绛山水
- **绛红**：胭脂 + 朱磦 + 极少墨；用途：暗红衣饰、秋叶。游戏中压低饱和度更耐看
- **紫**：胭脂 + 花青；用途：紫花、果实、衣饰。中国画式紫色应偏灰、偏深
- **米黄**：藤黄约70 + 赭石约30；用途：背景统一色、重彩底色。常见现代国画教学比例
- **檀香色**：藤黄约70 + 朱磦约20 + 三绿约10；用途：背景、嫩芽、托叶。常见现代国画教学比例

## 题材用色数据库

### 山水
- **山石阳面/暖面**：主色 赭石, 赭黄；暗部 淡墨, 花青；点色 三绿。浅绛：赭为主，色薄；结构先由墨建立。
- **山石阴面/背阴**：主色 花青, 墨青；暗部 重墨；点色 二青。偏冷、偏灰，避免纯蓝。
- **青绿山顶/主峰**：主色 二青, 三青；暗部 头青, 墨青；点色 二绿, 泥金。青绿重彩才提高矿物色覆盖感；主峰可比山脚更浓。
- **山坡/山脚**：主色 二绿, 三绿, 汁绿；暗部 老绿, 花青；点色 赭石。绿色浓度通常低于视觉中心，和赭色交错。
- **远山**：主色 清墨, 淡墨, 花青；暗部 墨青。低饱和、低对比、与纸色混合；不要画成实体蓝山。
- **水面**：主色 生宣纸白, 花青, 清墨；暗部 淡墨。以留白为主体，只在波纹、岸线、倒影处着色。
- **云/雾**：主色 生宣纸白, 蛤粉；暗部 清墨, 青灰。大面积留白；颜色只负责边缘和体积。
- **树干/枯木**：主色 赭石, 赭墨；暗部 浓墨；点色 赭黄。枝干不要统一棕色平涂，要保留墨线。
- **树叶/苔**：主色 草绿, 汁绿, 二绿；暗部 老绿, 墨绿；点色 藤黄, 三绿。春嫩黄绿、夏浓绿、秋赭朱、冬墨赭。

### 花鸟
- **正叶**：主色 草绿, 二绿；暗部 老绿, 花青；点色 三绿。正叶通常比反叶深。
- **反叶/嫩叶**：主色 汁绿, 三绿；暗部 草绿；点色 藤黄。更亮、更黄、更薄。
- **红花**：主色 朱磦, 朱砂；暗部 胭脂；点色 蛤粉。外瓣可浅，花心与瓣根加胭脂；避免荧光正红。
- **白花**：主色 生宣纸白, 蛤粉；暗部 花青, 汁绿, 清墨；点色 蛤粉。白花靠周围与淡影显形，不要全涂纯白。
- **黄花**：主色 藤黄, 石黄；暗部 赭黄, 朱磦；点色 蛤粉。藤黄偏透明，石黄偏重彩。
- **紫花/果实**：主色 紫（胭脂+花青逻辑）, 葡萄紫；暗部 花青, 胭脂；点色 三青。降低饱和度，让紫色保持灰雅。
- **枝条**：主色 赭石；暗部 赭墨, 浓墨。老枝重墨赭，新枝稍暖。
- **鸟羽黑部**：主色 浓墨, 重墨；暗部 焦墨；点色 清墨。用墨层级而非纯#000000。
- **鸟羽白部**：主色 生宣纸白, 蛤粉；暗部 清墨, 青灰；点色 蛤粉。保留纸白，少量灰青塑形。

### 人物
- **肤色基础**：主色 蛤粉, 赭石, 朱磦；暗部 赭石, 胭脂；点色 蛤粉。游戏数字化建议：白粉为体、赭石定结构、朱磦/胭脂给血色；不做西式高饱和肤色。
- **仕女/少年提白**：主色 蛤粉, 熟宣暖白；暗部 淡赭石, 清墨；点色 朱磦, 胭脂。额、鼻、下颌等可有传统提白意味，但游戏中应弱化成局部亮面。
- **男子/老人肤色**：主色 赭石, 赭黄；暗部 赭墨, 胭脂；点色 朱磦。减少白粉，提高赭色与墨的结构比例。
- **黑发/须**：主色 浓墨；暗部 焦墨；点色 淡墨, 青灰。避免死黑；边缘可留淡墨过渡。
- **素色衣**：主色 熟宣暖白, 米黄, 豆绿, 三青；暗部 清墨, 青灰。大面积衣服优先低饱和浅色。
- **重彩衣**：主色 朱砂, 二青, 二绿；暗部 胭脂, 头青, 头绿；点色 泥金。一件衣服通常只设一个强主色，金色只做线与纹样。

### 建筑与器物
- **朱柱/栏杆**：主色 朱砂, 朱磦；暗部 胭脂, 墨红。降低饱和度并保留墨线，避免现代大红塑料感。
- **青绿琉璃/彩绘**：主色 二绿, 二青；暗部 头绿, 头青；点色 泥金。适合宫观、仙家建筑的局部，不建议全建筑铺满。
- **灰瓦**：主色 重墨, 青灰；暗部 浓墨；点色 清墨。灰瓦本质是墨色体系，不是蓝灰PBR。
- **白墙**：主色 熟宣暖白, 蛤粉；暗部 清墨, 赭灰。暖白为主，墙脚可赭灰。
- **木梁/门**：主色 赭石, 古铜色；暗部 赭墨, 浓墨；点色 赭黄。旧木偏灰、偏赭，不宜橙色过饱和。
- **金属/法器**：主色 泥金, 古铜色；暗部 赭墨；点色 金箔色, 泥银。金色面积越小越显贵；优先线、边、纹。

### 天气与季节
- **春**：主色 汁绿, 三绿, 藤黄；暗部 花青；点色 胭脂。明度稍高，饱和度仍受纸色压制。
- **夏**：主色 草绿, 二绿, 花青；暗部 老绿, 墨绿；点色 三青。层次深，绿不宜统一。
- **秋**：主色 赭石, 藤黄, 朱磦；暗部 胭脂, 赭墨；点色 朱砂。用赭、黄为主体，朱砂只是点睛。
- **冬/雪**：主色 生宣纸白, 蛤粉, 清墨；暗部 花青, 青灰；点色 赭石。雪主要靠留白，树石以墨赭反衬。
- **雨雾**：主色 清墨, 青灰, 花青；暗部 淡墨。整体降低对比与饱和度。
- **夜**：主色 墨青, 花青, 浓墨；暗部 焦墨；点色 泥银, 三青。不是纯深蓝夜景；仍以墨为主。

### 修仙游戏扩展（非传统定式）
- **上界/仙境**：主色 三青, 三绿, 熟宣暖白；暗部 花青, 青灰；点色 泥金, 云母白。矿物青绿+大量纸白，金色少量。
- **幽冥/阴界**：主色 墨青, 灰绿, 黛青；暗部 浓墨, 焦墨；点色 三绿, 泥银。以墨青灰绿构成，不要荧光青绿；亮色只用于魂火/裂隙。
- **宗门/庄严空间**：主色 朱砂, 赭石, 青灰；暗部 浓墨；点色 泥金。朱、墨、金形成礼制感；控制金和朱的面积。
- **秘境/异常地形**：主色 二青, 二绿, 赭石；暗部 墨青；点色 云母白, 泥金。先保持传统色域，再用一个异常色作为唯一视觉事件。
- **灵气/法术**：主色 三青, 三绿, 蛤粉；暗部 花青；点色 云母白。不要做霓虹RGB发光；更像矿物粉尘、留白与薄罩染。

## 历史依据与使用边界
- 香港故宫文化博物馆“传统颜料”资料列出朱砂、赭石、朱磦、藤黄、花青、石青、石绿等，并指出石青/石绿按研磨沉淀颗粒可分头青、二青、三青与头绿、二绿、三绿；墨有松烟与油烟等。
- 故宫博物院“浅绛法”指出浅绛山水主要使用藤黄、花青、赭石，胭脂等为辅助，石青石绿即使使用也多薄染。
- 中国国家博物馆对清代青绿山水的科学检测发现：山顶、山坡、山脚及树叶使用石青、石绿等，树干使用赭石，枝条、屋顶、小桥等使用炭黑，并通过浓度变化表现山体起伏。
- 波士顿美术馆对明代中国画颜料分析确认了铅白、朱砂、铅丹、炭黑、铜绿、石青、花青与金等传统材料。
- 中国美术学院社会美术水平考级中心的人物画技法说明中，人物面部可先以赭色分染；传统仕女可使用白粉与朱磦、藤黄等综合色，男子肤色常以赭石、朱磦、藤黄与少量白粉组织。

## 安全说明
雌黄、雄黄、铅白、朱砂等历史颜料涉及砷、铅、汞等有害物质。本包仅提供数字颜色参考，不构成真实颜料购买、制作或使用建议。
