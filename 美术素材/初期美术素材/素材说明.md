## 三、关键约定（不可违反）

### 1. 精灵方向：脚在 y = 0

**Canvas 数组 row 0 = 脚；写盘时做了垂直翻转** ⇒ **PNG 文件里脚在图片底部**，
正好匹配 `DataTexture(flipY=false)` 的 UV 映射（数据 row 0 → UV v=1 → Plane 底）。
**游戏里脚贴地，方向自洽。**

### 2. billboard 接入

```js
const tex = new THREE.TextureLoader().load('美术素材/植被/tree_pine.png');
tex.magFilter = tex.minFilter = THREE.NearestFilter;   // 像素清晰
tex.colorSpace = THREE.SRGBColorSpace;
tex.needsUpdate = true;

const mat = new THREE.MeshLambertMaterial({
  map: tex, alphaTest: 0.5, side: THREE.DoubleSide
});
```

| 用途 | 几何 | 备注 |
|---|---|---|
| 植被 | `PlaneGeometry(1, 1.5)` + `translate(0, 0.75, 0)` | 与 `VegetationLayer` 一致（2:3） |
| 人物 / 鬼修 | `PlaneGeometry(1, 1.25)` | 4:5，脚对齐 plane 底 |
| 建筑 / 浮空岛 / 上界 / 幽冥物件 | `PlaneGeometry(1, 1)` | 1:1 |
| 地形 / 水文贴片 | 直接做 UV 采样源或 `InstancedMesh` 平铺 | 32×32 可平铺 |

⚠️ **半透明素材**（鬼魂 / 鬼修 / 云雾 / 阴气 / 冥河 / 水花）自带 alpha<255：
用 `alphaTest` 会切掉边缘，应改 `transparent: true, depthWrite: false` 并靠后排序绘制。

### 3. 图标 / 界面（24×24 · 48×48）

不透明纸底 + 圆角 + 细墨边，UI 直接贴，无需 alphaTest。
配合 `image-rendering: pixelated;`。
`ui_panel_9slice.png` 与三个 `ui_realm_frame_*.png` 都是 **48×48 九宫格**：四角 16px 固定。
