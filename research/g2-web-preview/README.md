# G2-W Presentation 工坊

无需 Node 构建、无需 CDN。仓库根目录执行：
  python -m http.server 8000
然后访问 http://localhost:8000/research/g2-web-preview/index.html

五个页签：开天、众生面相（64 枚头像）、交战状态（24 条有界观测和压力刷新）、卜算子（待命/未来任务 fixture）、界缘墨痕（四种交界、4 个缩放档）。

**所有数据均是 fixture，不是真实世界。** 在此工作台点击创建、导入、委托、定位或帮助，只会在下方打印意图或更新演示 ViewModel。不会创建世界、存取 localStorage、接入战斗或驱动 NPC。

浏览器静态页的人工/自动化实际验收需另行完成；代码存在并不意味着浏览器门禁已通过。
