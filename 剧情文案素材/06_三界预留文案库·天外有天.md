## 〇、三界的世界观坐标（写之前先读）

```
              上界 · 紫霄（云海仙山，无凡人，最低也是修士；大乘为止）
                  ↑ 飞升 / 裂缝吸人        ↓ 仙使下凡 / 裂缝漏物 / 仙战坠物
              ─────────── 空间裂缝（玩家开「上界视界」的副作用，在划选边缘）───────────
                  ↑ 死亡留魂              ↓ 转世 / 夺舍
              幽冥 · 冥河（魂池、鬼修、轮回；幽墨冥河图，一条横向冥河）
```

**七条不许写错的设定**（文案必须与机制对得上）：

1. **上界开局只有十二人**（三条始祖线各四人），人口只靠「飞升上来的人」与「上界繁衍」两条腿，没有第三条（灵气化生被用户否决）。
2. **上界没有凡人**。凡人飞升不了；被裂缝吸上去的凡人 = **失踪**，井里记「走失」，上界有一本可查的名册（`mortalLog`），但人不进上界实体。
3. **上界也打仗**，战争是人口调节阀；仙门之间为仙脉、为道理开战。
4. **裂缝是玩家开视界的副作用**，开在划选区域的**四条边上**；先涨后缩，一条缝从开到闭约三四十年，一生只漏几件东西，「轻微，初期不是灾难」。
5. **裂缝漏物有方向**：上→下漏法宝、仙草（凡间磕头叫天赐）；下→上吸修士（跨界）、吸凡人（失踪）。
6. **幽冥是魂的去处**：死后分五路——自然转世、滞留幽冥、成鬼修、怨魂化、魂火散尽；
   鬼修六级：游魂 → 怨灵 → 厉鬼 → 鬼将 → 鬼王 → 鬼帝；幽冥三物：轮回莲、聚阴符、驱鬼符。
7. **跨世界转移只认快照，不认人**。两界 id 各自从 1 数起，文案里不许出现「上界第 N 号修士」式的编号穿帮；
   飞升者只带「来自凡间」的来历（姓名、宗门名、年代、境界），不带任何关系 id。

**境界对照**（文案称谓以此为准，不得新造境界名）：
炼气 → 筑基 → 金丹 → 元婴 → 化神 → 合体（凡间之巅）→ **大乘**（上界境界，寿元万六千载，大乘大圆满为止）。
「剑仙 / 丹仙 / 阵仙 / 符仙 / 散仙」是**仙使类型 / 尊称**，不是等级。

## 一、上界风物（upper · 视界首次看见时的环境文案）

> 接线：第十式「上界视界」开窗后的环境描述、上界检视面板、上界地图空状态。
> 视觉基调：上界沿用水墨但偏亮、偏冷、云海留白多；与凡间的暖墨、幽冥的冷墨成三界三色。

### 1.1 初窥（视界开窗）

- G01-01　【预留】云开一角，露出上面的山河：山浮在云上，河倒挂在天里，没有田垄，没有炊烟。
- G01-02　【预留】这一层的墨色淡，像有人画到一半停了笔。住在这里的人太少，笔舍不得落重。
- G01-03　【预留】下界仰头看了千万年的「天」，从这扇窗看下去，不过是另一层地。
- G01-04　【预留】上界听不见鸡鸣犬吠。风过仙山，空得像一口刚铸成、还没装过东西的钟。
- G01-05　【预留】（上界人口极少时）云海里数得清的人影，一只手数得过来。他们各占一座山头，互相望得见，几百年不走动一回。

### 1.2 上界地名与风物（供上界地点 / 面板衍生素材，不新造宗门名）

- G02-01　【预留】上界的河不往低处流，往灵气浓处流；上界的人不往热闹处去，也往灵气浓处去，所以河与人，常在一处撞上。
- G02-02　【预留】云海之下是凡间的屋顶，云海之上是仙门的飞檐。同一场雨，先敲仙门的瓦，再敲凡人的窗。
- G02-03　【预留】此地仙脉凝成露，挂在草叶尖上，三百年不落。下界一株灵草争破头，这里的鹿低头就喝，喝惯了，不觉得稀罕。
- G02-04　【预留】上界没有城，只有「仙城」：一座城围着一座仙门，城里住的最低也是金丹，卖饼的摊主，可能比你凡间的掌门辈分还高。
- G02-05　【预留】（上界战争遗迹）云海上浮着半截断山，切口平整，是早年仙战的余波。断山不坠，也不长草，就那么悬着，像一道不肯结痂的伤。
- G02-06　【预留】上界的夜没有月亮，灵气浓处自生光，远看像云海里落了星子。飞升者头一夜都睡不着，云海亮如黄昏，思乡反倒排到了第二夜。
- G02-07　【预留】上界的风有重量，从两座仙门之间过一趟，衣袍上沾的灵气够下界修士打坐半月。所以上面的人走路慢，风拖着衣袍，外人只当他们端架子。
- G02-08　【预留】云海深处有「听云坪」，飞升者爱去那儿坐着，云下偶尔飘上来凡间的鸡犬声、哭嫁声、磨刀声，听不清，又像听得清。

### 1.3 上界空状态（视界里暂时无人 / 无门）

- G03-01　【预留】这片云海还没有主人。飞升者会落在灵气最厚的地方。在那之前，山和云都只是山和云。
- G03-02　【预留】上界还没有仙门。十二位始祖各修各的，要等他们的弟子的弟子，才想得起「立宗」两个字。
- G03-03　【预留】没有人的上界，像一本翻开的空白册子。字会有的，从井里一笔一笔飞上来。
- G03-04　【预留】视界开得太早，云海上连个脚印都没有。别急，你井里那些磕头求仙的，迟早有人磕上来。
- G03-05　【预留】这座仙城还只有个名字，城里的砖要等飞升者自己搬。在井里他们是被人供着的，到了上面，头一件功课是当匠人。

## 三、上界仙门与战争（upper sect & war）

> 接线：上界 `stepSects`（仙城化）/ `stepWar`（复用 war.js，传独立随机流）。
> 基调：仙门战争比凡间「讲究」，也比凡间「狠」；凡间抢地，上界抢道理、抢仙脉、抢「谁的道才是道」。

### 3.1 仙门初立

- G07-01　【预留】上界第一座仙门悬匾。没有万民来贺，云海之下也听不见鞭炮，十二位始祖里去了七位，剩下五位托人带了话：匾挂正些。
- G07-02　【预留】仙门立规第一条，不戒杀、不戒贪，戒「同门相轻」。立规的始祖说：凡间的宗门怎么散的，我在井里看得清清楚楚。
- G07-03　【预留】仙城围着仙门长出来。城里第一家铺子不卖丹药，卖的是「凡间风物」：一捧故土、半块粗饼、一缕炊烟封在符里，飞升者买得最多。

### 3.2 仙战（上界战争）

- G08-01　【预留】上界两门会战于云海之墟。没有凡人围观，没有卖瓜子的。这一仗安静得很，只有剑气相撞时，云被劈开又合拢的声音。
- G08-02　【预留】仙战起于一处仙脉的归属，终于一篇谁也没说服谁的道论。地没抢成，道理也没辩成，两边各折了一位真人，各自回山，关门百年。
- G08-03　【预留】上界仙战，败者不割地，云海上没有地契；败者让出的是「讲经的座次」。在上面，座次比地要紧。
- G08-04　【预留】（仙战波及凡间）上界斩落的飞剑、崩碎的符箓坠下云海，凡间{place}落了三日「星铁雨」。井里的铸师那年没进过一块新矿，都跪在院里捡。
- G08-05　【预留】仙战之后，两门弟子在云海渡口撞见，互相让了让，谁也没说话。上界的仇不挂在脸上，挂在下次论道谁先开口。
- G08-06　【预留】（人口调节的史笔，不直说机制）仙门盛极而战，战而后稀，稀而后安，安而后又盛。云海翻覆，上界的人数始终在一条线上下浮着，像有人替这一层天留了个透气的口子。

### 3.3 上界陨落

- G09-01　【预留】{name}陨于上界仙战。凡间无人知晓。他飞升已三百年，记得他的人都已作古，只有{place}那座空洞府，梁上的灰又厚了一层。
- G09-02　【预留】上界修士坐化，不立坟，法身化作云气归入云海。门人说师长「回云里去了」，就像凡间说人「回老家了」。
- G09-03　【预留】飞升者{name}寿尽于上界。他比在凡间多活了九千载，临终却念叨一口凡间的粗茶。上界什么都有，唯独没有那口涩。
- G09-04　【预留】（上界魂归幽冥，待拍板路线）上界陨落者的魂，沿一条凡间看不见的冥河支流下归幽冥。幽冥的册子不分上下界，魂到了河边，都一个价。

## 四、空间裂缝（rift · 编年史与世界内文本）

> 接线：`world.rifts` / `riftLog`；裂缝开在划选视界的四条边上，先涨后缩。
> 基调：**初期是奇观与机缘，不是灾难**；裂缝最伤人的不是吞东西，是「失踪」两个字。
> 占位符：{place}{n}{name}{artifact}{item}。

### 4.1 裂缝初开 / 张大

- G10-01　【预留】{place}天际忽现裂痕，初如发丝，渐若刀劈，中有光气漏下。乡人以为天门开，设案而拜；唯修士面色发白，他们看得出，那是两层天磨出来的伤口，不是门。
- G10-02　【预留】裂隙横在{place}山梁上，边沿的树往天上长，河里的鱼往云里游，过了那道线，连风都不认方向了。
- G10-03　【预留】裂缝开了三年，{place}的人渐渐习惯了天上那道亮。孩子拿它当月亮数，老人不许孩子指，指天，不敬。
- G10-04　【预留】（开到最盛时）裂隙最宽那夜，{place}亮如白昼，上下两界的山河在缝里叠在一起：一座山上长着两片天的树，一条河里游着两界的鱼。

### 4.2 上界漏物（上 → 下）

- G10-05　【预留】裂隙坠下一件法宝{artifact}，落在{place}。捡到的人连磕了九个头，管这叫「天赐」；他不知道，上界失主正沿着缝边骂街。
- G10-06　【预留】{place}有仙草自缝中飘落，入土即活，叶尖朝天上那道缝长。采药人发了笔横财，逢人便说祖宗积德，绝口不提那道缝。
- G10-07　【预留】裂隙漏下半页上界经书，被{place}蒙童捡去包了油条。多年后修士见到那半页字，脸色大变，再找蒙童，油条早吃下肚了。
- G10-08　【预留】（小物什，趣味）缝里掉下来一只上界的仙鹤，落地后脾气极大，不吃凡间的粮，只对着裂缝的方向叫，叫了七天，第七天缝又开了一瞬，它自己飞回去了。
- G10-09　【预留】裂隙漏下一场上界的雨，落在{place}三伏天，落地成冰，孩童当糖啃了三天。老中医说那冰治好了几个人的咳喘，也冻坏了两口井。

### 4.3 修士被吸（下 → 上 · 跨界）

- G11-01　【预留】修士{name}过{place}，被裂隙摄去，众目睽睽之下人影渐淡，最后只剩一句话从半空飘下来：「剑——替我还给师父。」
- G11-02　【预留】{name}踏入裂缝，从凡间的{place}走到了上界的云海。他成了极少数「没靠飞升就上去」的人。上界仙册在他名字旁边，画了个小小的问号。
- G11-03　【预留】被吸上去的修士后来托裂隙漏回一缕传音。{place}的同门只听见半句：「上面……也是要排队的……」余音被风卷走。

### 4.4 凡人失踪（下 → 上 · 「失踪 + 上界可查」）

> 这是裂缝文案的**戏眼**，也是用户专门拍板的机制。井里记「走失」，上界有名册，人不进上界实体。
> 克制写，不写嚎啕，写碗筷、牌位、没法办的丧事。

- G12-01　【预留】{place}民某耕于野，被天光摄去，唯余锄头插在田心。县志书「走失」，家里偏不认这两个字，每日仍在田边放一碗饭。
- G12-02　【预留】裂隙过{place}，一樵子、一货郎、一未嫁女同时失踪。三人互不相识，名字却并排刻上同一块「归无碑」。活着的人，只能给没处找的人立碑。
- G12-03　【预留】其子沿缝寻父，寻到{place}，缝边守了三年。三年里他学会了看缝：哪片云要漏光、哪阵风往上走。他没寻见父亲，倒成了方圆百里最懂天的人。
- G12-04　【预留】失踪者的牌位不入祖坟。没有尸身，也没有死讯，族人说「不好立」。其妻不说话，当夜在自家灶房另立一块小牌，牌上不写「亡」，写「未归」。
- G12-05　【预留】（上界名册侧，即「在途簿」）上界仙城角落有一册无人问津的簿子，记的是被缝误摄的凡人：姓名、乡里、走失年月。仙官说这些人「未登仙界，亦失故井」，簿子的封皮上写着两个字：在途。

## 五、幽冥界（nether · 冥河、魂路、鬼修）

> 接线：幽冥地图（`upperworld.md §8`）、`reincarnation.js` 魂池、鬼修实体、幽冥三资源。
> 视觉：幽墨冥河图（`nether-dark-river`，一条横向冥河，魂出生在河边窄带）。
> 基调：幽冥不恐怖，**幽冥讲规矩、讲账目、讲排队**；吓人的是在冥河边看见熟脸。

### 5.1 冥河与渡口

- G13-01　【预留】幽冥无日月，只有一条河，河上无波，水面照得见每个人死前最后看见的东西。
- G13-02　【预留】新魂到河边，先要在水里看一眼自己。有人看了就肯过河，有人站在岸边看了一辈子，那是阳间的一辈子，在这儿只是一瞬。
- G13-03　【预留】冥河没有摆渡人，也没有船。魂到了时候自己会往对岸走，走到一半还回头的，就留下了。
- G13-04　【预留】河边有石，魂过石前会轻一钱，轻的是怨气。怨气重的过不了石，石头把他们留下，慢慢磨。
- G13-05　【预留】幽冥的风不冷，冷的是风里传来的、阳间人喊你名字的声音。听见了回头的魂，要多排一百年的队。

### 5.2 魂分五路（natural / linger / ghost / wraith / gone）

- G13-06　【预留】（自然转世）魂清如水，冥河照不见影子，这样的魂，对岸接得最快，阳间哪家孩子落地，这边正好放行。
- G13-07　【预留】（滞留幽冥）有些魂在河边坐下了，说等一个人。河官不催，只在册子上批「在等」二字；阳间多少痴守，到了阴间还是痴守。
- G13-08　【预留】（成鬼修）聚阴符的光在冥河上一闪，【{name}】睁开了没有瞳孔的眼睛。他不肯过河，他要带着这一世的本事，再活一遍（注：鬼修）。
- G13-09　【预留】（怨魂化）【{name}】死后怨念与浊气纠缠，不入轮回，化作怨魂。那双眼里的恨，连冥河都照不亮。
- G13-10　【预留】（魂火散尽）也有魂走到河心，自己散了，像一盏油尽的灯。河官在册子上勾掉名字，不写死因，能走到自己散的，多半已经不累了。
- G13-11　【预留】冥河不涨不落，水色随过河的魂变：清魂过水，河面照得见云；怨魂过水，河水浓得像研不开的墨。艄公不看魂，看水，就知道今天要渡几趟。
- G13-12　【预留】（滞留）有些魂坐在渡口不走，不怨也不恨，就是坐着。问他等什么，他说等一个还没死的人。艄公听了也不催，只把船往岸边多靠半尺。

### 5.3 鬼修六级（游魂 → 怨灵 → 厉鬼 → 鬼将 → 鬼王 → 鬼帝）

- G14-01　【预留】（游魂）新成的鬼修叫游魂，记不得自己为什么不肯走，只记得阳间有个方向，一走就疼，不走去想，更疼。
- G14-02　【预留】（怨灵）游魂积了怨，成怨灵。怨灵过境，冥河边的磷火齐齐矮了一寸，连鬼都怕鬼。
- G14-03　【预留】（厉鬼）厉鬼成形，阳间那一头，他枉死的地方连夜草上结霜。驱鬼符上画的，正是这一副模样。
- G14-04　【预留】（鬼将）鬼将统百鬼，在冥河下游列阵。他们不渡河，也不许别的鬼乱渡河。鬼修到了这一级，反倒替幽冥管起事来。
- G14-05　【预留】（鬼王）鬼王出世，阴阳两界的井水同时晃了晃。阳间的皇帝祭天，阴间的河官上岸，为的都是同一位。
- G14-06　【预留】（鬼帝）鬼帝不轻易现世。传说他若过河，轮回要停三日；他若回头，阳间要多一城枉死的人。所以他从不回头，只在河尽头坐着，替所有不肯走的魂，看着对岸。

### 5.4 幽冥三物（轮回莲 / 聚阴符 / 驱鬼符 · 天道在幽冥的手笔）

- G15-01　【预留】（轮回莲）冥河淤处生莲，莲开则魂近，魂触莲花，前尘尽洗，登对岸，入轮回。莲花一年开一度，度魂不论善恶，只论轮到没轮到。
- G15-02　【预留】（聚阴符）聚阴符落处，游魂聚而成修。这符是给「不甘心」的人留的一条岔路：轮回是答卷，鬼修是留级，留级的，总得有间教室。
- G15-03　【预留】（驱鬼符）驱鬼符不杀鬼，只把弱小的怨魂吹散在河边。吹不散的，是真有冤；吹得散的，是只剩一口怨气撑着的可怜人。
- G15-04　【预留】（天道手笔的史笔）幽冥三物，一者送人走，一者留人住，一者赶人散。掌幽冥的河官说：这三样东西，是「上面那位」可怜井里的人，留的三条退路。

### 5.5 怨魂灾（wraithPressure 越界）

- G15-05　【预留】怨魂压力越过临界，阴地爆发怨魂灾，冥河倒灌，鬼潮冲击轮回渡口。河官的册子被风吹乱，那一页，生死簿上多了许多来不及勾的名字。
- G15-06　【预留】阳世连年刀兵、妄杀过重，幽冥这边河边便站满了不肯走的魂。阳间的人不知道：他们每多造一桩枉死，冥河上就多一个等不到船的影子。
- G15-07　【预留】（玩家天火/绝灵地影响幽冥的侧写，机制：天火+4 怨魂压力 / 绝灵地+3 阴窟 / 洞天-2）阳世落天火之夜，幽冥的磷火无端旺了三分；阳世开出洞天，冥河便安静一段时日。两界的账，原来是同一张纸的正反面。

### 5.6 转世规则（补「幽冥没有规则」的文案侧）

- G16-01　【预留】魂入轮回，阳间的落生也讲般配：清魂厚福之家，残魂寻常门户。厚福人家接得住旧魂带来的那点东西，与贫富无关。
- G16-02　【预留】大修的魂不肯轻投，在冥河上等了又等，等一处灵气厚、肯读书、积善三代的人家。河官笑他：你这不是投胎，你这是挑宅子。
- G16-03　【预留】（高魂拒投薄地，若实装）有{realm}旧魂三次推却贫瘠门户，第四次河官不允了：再挑，你就该挑成滞留户了。魂这才怏怏而去。后来那家里，果然出了个神童。
- G16-05　【预留】（转世成邻人）有魂过了河，投在旧居隔壁。三岁那年他指着隔壁老妇说「这是我屋里的」，老妇抱着他哭了一下午，此后两家再没分过锅。
- G16-04　【预留】转世不喝迷魂汤（此界无孟婆），前尘是自己碎的：过一次河碎一层，碎得干净的是福气，揣着碎片上岸的，是文章，也是病。
